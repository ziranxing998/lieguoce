# 列国策（LieGuoCe）

> **一句话**：一款以中国先秦为背景的大型多人在线策略游戏——**AI 扮演各国君主**制定国策，玩家扮演"士"接诏办差、上书议政、出将入相。君主是活的，国运是涌现的。

**当前状态**：概念与系统设计已定稿（11 份系统设计文档 + 技术方案），网页试玩版已可玩（单文件实现，核心循环：旬制决策 → 国策诏 → 任务 → 国力 → 下一旬）。

## 三条项目铁律（违反 = 设计失败）

1. **玩家主权**：玩家手动决策权限永远大于 AI。AI 能做的玩家都能手动做；手动随时覆盖 AI；玩家在线时 AI 让位；离线可授权下放。
2. **成本敏感**：每个系统必须证明运营成本可负担（个人开发者项目）。AI 决策走旬制批处理；自由对话只开放给大夫以上官职。
3. **决策与执行等价**：文臣定策、武将执行，两路成长速度等价（±10% 带宽），不逼玩家搞政治玩法。

## 参考系

- 借鉴《率土之滨》的**运营骨架**：大服容量（单服目标 1000-3000 人）、赛季制、列国对抗；
- 借鉴《文明》系列的**玩法内核**：文臣的"方略树"（如科技树）、武将的节点战术；
- **明确拒绝**：格子占地攻城、卡牌收集、数值堆砌、"一人操控全国"的单机节奏。

## 试玩版怎么跑起来

纯静态单文件应用（`game/index.html`），依赖 WorkBuddy 云服务（云数据库 + 免密钥大模型）。三种玩法：

- **本地直接玩**：双击 `game/index.html` 即可（需要已配置的云服务端点，见文件内 `PUBLIC_CONFIG`）；
- **接入自己的后端**：改 `PUBLIC_CONFIG` 指向任意兼容 PostgREST 的服务 + OpenAI 兼容的大模型接口即可；
- **在线版**：当前部署在 `https://liguoce-trial.app.workbuddy.host`（账号属原作者，仅供体验）。
