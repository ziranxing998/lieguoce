## 1. 系统概述

**一句话**：AI 君主决策引擎是每国君主的"大脑"——它以人格卡为唯一权威源，聚合四层输入（国力仪表盘 / 玩家行为聚合 / 外交事件流 / 历史引力），按旬制节奏与事件触发两种模式产出结构化决策（国策诏、任务潮、事件诏令、君心语录），并维护跨旬、跨赛季的 AI 记忆与恩怨账本。

**在整体中的位置**：
- **它是《列国策》的中枢生产系统**：下游消费它的输出的系统包括——任务系统（接收任务潮）、国力系统（接收内政决策效果）、外交系统（接收诏令/照会）、朝堂与摄政系统（接收廷议/仲裁上下文）、史书系统（接收语录与决策记录）。
- 它对应 GDD-0 设计支柱一"君主是活的"的**全部机制载体**：玩家感知到的"君主有自己意志"，100% 来自本系统的输出行为。
- 它**不拥有**国力数值本身（属国力系统）、**不执行**任务发放（属任务系统）、**不裁决**摄政是否合法（属摄政系统，本系统只提供 AI 立场与理由）。

```
[输入层] 国力仪表盘 ─┐
         玩家行为聚合 ─┤
         外交事件流   ─┼─→ [AI 君主决策引擎] ─→ [输出层] 国策诏 / 任务潮指令 / 事件诏令 / 君心语录 / 内政效果指令 / 恩怨账本更新
         历史引力参数 ─┘            │
                              [摄政干预接口] ←→ 摄政系统（廷议仲裁）
```

## 2. 设计目标与反目标

### 目标（按优先级）

| # | 目标 | 验证方式 |
|---|---|---|
| G1 | **君主人格可辨识**：不看国名，仅凭诏令措辞与决策倾向可猜出是哪位君主 | 盲测：截图去标识后玩家猜国正确率 ≥ 60% |
| G2 | **决策可推断**：玩家能通过君心语录反推君主意图，形成"君心学"社群解读 | 语录截图率、玩家社群"猜君心"帖数量 |
| G3 | **决策与国力真实联动**：短板触发任务潮的反馈循环可被玩家感知 | 短板出现 → 对应任务占比变化的相关性 ≥ 0.7 |
| G4 | **行为连续一致**：同一君主前后决策不出现无理由自相矛盾 | 恩怨账本强制约束 + 季度人格回归测试 |
| G5 | **成本可控**：旬度决策批处理化，自由对话限频+预算熔断 | 单服日均 token 成本 ≤ 预算上限（见 7.3） |

### 反目标（本系统明确不做的事）

| # | 反目标 | 理由 |
|---|---|---|
| A1 | **不做开放式自由聊天客服**：自由对话仅限 3 个场合（L3 朝堂 / 摄政陈情 / 君心参悟追问），有频率与长度上限 | 支柱一红线：无限对话必然出戏且成本失控（GDD-0 风险 2） |
| A2 | **不做全能上帝**：AI 君主不拥有超出人格卡+四层输入的信息来源，不做"读心"式决策 | 决策必须可复盘、可解释；不可解释的智能会摧毁君心参悟玩法 |
| A3 | **不做数值自动平衡器**：不因"某国太弱"而偷偷给该君主开挂式内政增益 | 违反支柱二"国运涌现"；弱国补偿走明规则（小国倾斜政策，属国力/外交系统） |
| A4 | **不代替摄政系统裁决**：摄政冲突时本系统只产出 AI 立场、理由与威望判定输入，仲裁流程归属摄政系统 | 职责单一；胜负规则透明可复盘 |
| A5 | **不做实时逐秒决策**：所有常规决策收敛到旬制节拍，事件决策有冷却与去抖规则 | 节奏化决策是用户定稿 ✔；高频决策既贵又不可玩 |
| A6 | **不生成任务内容本身**：本系统产出"任务潮需求指令"（类型/权重/叙事包装），具体任务实例由任务系统生成 | 避免双头内容源导致任务文案与数据不一致 |

## 3. 系统拆解

### 3.0 模块总览（8 个子模块）

| 模块 | 职责 | 输入 | 输出 |
|---|---|---|---|
| M1 人格卡库 | 君主人格唯一权威源 | 运营配置 | 人格上下文（注入每次决策） |
| M2 决策输入聚合 | 四层输入清洗、汇总、异常剔除 | 国力系统/行为日志/外交事件流/引力参数 | 决策上下文快照 |
| M3 旬度决策流水线 | 每旬定时批处理主决策 | 快照 + 人格 | 国策诏 + 任务潮指令 + 复盘语录 |
| M4 事件触发决策 | 突发事件的即时决策（带去抖） | 事件流 + 快照 + 人格 | 事件诏令 + 应急任务 + 事件语录 |
| M5 任务潮生成 | 将决策意图转译为任务需求指令 | 决策输出 + 国力短板数据 | 任务潮需求单（交任务系统） |
| M6 摄政干预接口 | 摄政提案 → AI 立场与理由；接住威望判定 | 摄政系统提案 | AI 反对理由（君心形式）/ 接受指令 / 威望消耗裁定输入 |
| M7 君心参悟生成 | 为重大决策生成"含真实理由痕迹"的语录 | 决策内部依据（受控暴露） | 语录（入库前双审） |
| M8 AI 记忆 / 恩怨账本 | 跨旬跨赛季记忆：叛逃者、恩怨、承诺、重大事件摘要 | 决策历史 + 玩家行为事件 | 记忆检索结果（注入 M2/M3/M4）；跨季恩怨摘要（交史书系统） |

### 3.1 M1 人格卡库

- 每君主一张人格卡（字段规格见 §4.1），**唯一权威源**：任何其他文档/提示词引用人格，一律以卡为准。
- 人格卡分两层：**静态层**（性格五维、语料风格、偏置权重——赛季内不变，GM 可热更）与**动态层**（恩怨账本指针、当季历史引力上下文——随游戏进程更新）。
- 人格漂移防线：静态层写入 prompt 时的模板固定 + 文风过滤器（禁现代词汇表）+ 每季回归测试（用固定 20 条历史输入重放，对比决策倾向偏差，偏差 > 阈值告警）。
- ▲人格卡提示词组装属实现细节，与程基岩对齐后另出 ADR。

### 3.2 M2 决策输入聚合

- 每次决策前生成**决策上下文快照**（快照落盘，用于复盘与回归测试）。
- 四层输入的清洗规则：
  - **国力仪表盘**：取五维现值 + 近 3 旬环比 + 相对七国均值位置（避免绝对值比较造成小国永远"危机"）。
  - **玩家行为聚合**：任务类型完成率、上书议题统计倾向（去重：同一玩家同一议题每旬计 1 票，防刷）、活跃/流失分群摘要。**（REV-006 注记）客卿代拟内容（GDD-S7）计入玩家行为聚合时归因 player_id 不变——单玩家影响 ≤5% 的防操纵上限对客卿重度用户同样生效，现有护栏直接适用。****（v0.5 注记）override 语义**：玩家手动操作覆盖其客卿已提交操作（未到 M2 旬快照冻结前可撤销，撤销带 override 审计标记），聚合以覆盖后版本计——玩家主权原则（GDD-0 项目铁律）在本管线的落点。**（v0.6 注记）离线行为同口径**：客卿守舍之约（S7 §3.6）期间的离线动作以 player_id 归因、与在线行为同口径进入聚合，单玩家 ≤5% 上限不变。
  - **外交事件流**：近 2 旬他国诏令摘要、边境摩擦计数、会盟邀请状态（由外交系统推送，本系统不自行爬取）。
  - **历史引力**：当前时代命题 ID + 权重 + 距离触发的进度（GM 可调）。
- 异常剔除：单玩家行为对"玩家倾向"的最大影响权重上限 5%（防操纵）。
- **上书/议政案拆分口径（REV-WRITEBACK 修订：跨文档一致性，对齐 S13 §3.3 勘误）**：本层 `petition_tendency` 仅收**上书倾向票**（action_type=`memorial`）；**议政案**（action_type=`proposal`）**不入本层聚合**——经 S13 C3 呈递、S2 提案结构化后由 M3 旬决策裁决（采纳署名/驳回/存档），两通道不重复计票（S13 §6.2"唯一回流出口"口径同步）。

### 3.3 M3 旬度决策流水线

每旬（MVP-0 = 现实 **7 天**；V1 按容量档位可缩至 3 天，S11 P4 弹性参数——REV-WRITEBACK 修订：跨文档一致性，执行 S10 附录口径联动清单）定时触发，批量批处理执行，七国一次跑批。流程：

1. 生成决策上下文快照（M2）。
2. 召回记忆（M8）：恩怨账本 top-K 条目 + 上一旬决策复盘。
3. **决策主调用**（一次 LLM 调用产出结构化 JSON）：
   - 本旬《国策诏》2-3 条国家目标（须与人格偏置 + 短板数据自洽）；
   - 本旬任务池**主推方向权衡**（任务池由规则引擎确定性生成，见 M5；LLM 输出须引用任务池 ID，不得凭空造任务）；
   - **本旬待裁议政案裁决（REV-WRITEBACK 修订：跨文档一致性，对齐 S13 §3.3/§4.3 拆分口径）**：输入为 S13 C3 呈递的议政案池（`proposal_id` 列表 + dims_target 结构），逐案输出裁决——**采纳署名**（ADOPTED_SIGNED：入诏并绑定 goal_id，进 S2 策功归因链）/ **驳回**（REJECTED：附人格化理由语录，复用 M7 管线）/ **存档不议**（ARCHIVED）；裁决结果随本旬《国策诏》公示并回写 S13 C3 状态机（输出结构见 §4.3 `proposal_verdicts`）；
   - 内政效果指令（少量、温和的国力自愈行为，明示于诏令，见反目标 A3 约束）；
   - 上一旬决策复盘语录（连责性：须引用上旬语录中的目标，说明达成/未达成）。
4. 输出经结构校验（JSON schema 校验失败 → 重试 1 次 → 降级为模板诏令）+ 合规过滤后发布。
5. **失败降级链（v0.1 修订：架构对齐）**：主模型失败 → 备用模型 → **冻结上旬诏令 + GM 注入**（玩家可见文案："国事如常，新诏稍迟"类模板）→ 模板诏令库（人格卡预生成、按短板类型参数化）兜底，保证"每旬必有国策诏"的节奏承诺。

### 3.4 M4 事件触发决策

- **触发源白名单**（GDD-0 4.4）：宣战/停战申请、会盟邀请、天灾、重大玩家事件（刺杀君主、叛逃、复国宣战）。
- **去抖规则**：同类事件 12h 冷却；1 旬内事件决策 ≤ 3 次（超出则合并为一条"多事之秋"诏令）；低优先级事件攒至下一旬合并处理。
- 事件决策**必须先查恩怨账本**（M8）——如叛逃者再入境、盟友旧约——确保行为连续（目标 G4）。
- 事件诏令同样走结构化选项出口，不引入新的玩家交互形态。
- **与旬决策的时序规则（v0.1 修订：架构对齐）**：所有决策按**旬号+序号版本化**，事件诏令序号更高。同旬内事件诏令**覆盖旬诏冲突项**（如宣战当旬，旬诏中"与秦修好"类目标作废）；被覆盖项**不删除**、标注"已因时事更易"（保留可追溯性，对齐透明日志原则）；事件诏令须附一句理由化包装（**"形势骤变，君命有所不受"**式措辞，由人格卡语气生成）。冲突预防：旬决策生成时 M2 已注入当旬事件上下文，天然减少残留冲突。

### 3.5 M5 任务潮生成（v0.1 修订：架构对齐——两级架构）

- **两级拆分**（采纳架构基线策略 4 重大建议）：
  1. **规则引擎层（零 LLM）**：五维短板判定 → 人格偏置加权 → 任务模板库抽取 → 产出**结构化任务池**（确定性、可审计、数值可控）。
  2. **LLM 权衡层**：仅在任务池中做本旬**主推方向权衡**（引用任务池 ID）+《国策诏》叙事文本与语录。
- **支柱一影响评估（结论：无损，且更稳）**：玩家感知"君主是活的"的通道是**诏令叙事、语录、任务包装语**——这些全部仍由 LLM 生成；任务数值本身从来不是玩家可感知的人格载体，且确定性数值反而保证"韩君连续两旬都推民生任务"这类行为连续性（目标 G4）不出戏。风险点在任务包装语需携带人格语气：模板库按 7 国人格 × 任务类型预写变体，M5 权衡层输出时附叙事包装语。
- 输入：国力短板数据 + 人格偏置 + 上书倾向 + 方略树长期修正（经 M2 快照第①层注入，改权重底数不生成任务——REV-WRITEBACK 修订：跨文档一致性，承 S2 v0.10 注记）+（MVP 后）摄政优先级覆盖。
- 加权规则伪代码见 §4.4。
- 红线落实：同一维度任务潮有**旬内占比上限**（默认 40%），防止任务潮过拟合单一短板 → 玩家刷单一任务 → 收益递减惩罚（与国力系统 GDD 对齐 ▲）。
- **战时模式参数（REV-004 修订：战时模式，主理人批准）**：该国进入战争状态（S3 会战实例 DECLARED 至 SETTLED/CANCELLED）期间，任务潮单维度占比上限由 40% 提升至 **60%**（豁免范围：军事/后勤类任务），停战即恢复 40%。理由：战时全国总动员本身是单维压倒性投入的叙事常态，40% 上限会阻止"举国支前"的动员感；豁免仅限军事/后勤类，防借战时状态刷经济/民生收益。参数入 N7（S2）GM 调参清单。
- 输出"任务潮需求单"为纯数据结构（类型/数量/权重/叙事包装语），任务系统负责实例化——职责分离（反目标 A6）。

### 3.6 M6 摄政干预接口

摄政系统的四项可干预权限全部经由本接口落地：

| 摄政权限 | 引擎侧处理 |
|---|---|
| 任务潮优先级排序 | M5 接收优先级覆盖，但**人格偏置权重仍生效**（覆盖的是排序，不改权重底数） |
| 战时动员令节奏 | M4 接收节奏参数，事件决策合并窗口按其调整 |
| 俸禄/封赏分配比例 | 透传至经济/俸禄系统，引擎仅记账（恩怨账本记录摄政政绩） |
| 廷议议题发起（每旬 1 次） | 引擎生成 AI 立场与反对理由（君心形式），提交摄政系统仲裁流程 |

- **冲突仲裁中引擎的职责边界**（对齐反目标 A4）：引擎输出 = ①AI 反对理由文本（引用国力数据，可被玩家复盘）②该议题的 AI 倾向分（-5 ~ +5，交摄政系统计算威望消耗量）。**不做**最终胜负判定。
- 强行推行成功/失败、威望值变动结果回写恩怨账本，影响君主对摄政的后续态度（MVP 中仅记录，V1 起影响"信任/猜忌"动态 ▲远期）。

### 3.7 M7 君心参悟生成

- 每条重大决策（国策诏各条、事件诏令、廷议反对理由）附一段语录。
- **生成约束**：
  - 输入 = 决策的**真实内部依据**（短板数据、恩怨条目、引力进度），但**只暴露痕迹不暴露数值**（例：不写"民生环比 -8%"，写"去岁仓廪之耗，寡人夜不能寐"）。
  - 语气模板来自人格卡语料库；先秦语感检查（禁词表 + 句式校验）。
  - **双审入库**：机器审（合规+风格）→ 抽样人工审（运营），未过审语录降级为模板语录。
- 语录是 AI 可解释性的玩家侧载体（GDD-0 4.5），**每条语录必须能对应到至少 1 条真实决策依据**——这是 G2"可推断"的硬保证，由生成时强制传入依据字段实现。

### 3.8 M8 AI 记忆 / 恩怨账本

- 数据结构：每君主一份恩怨账本（规格见 §4.3）。
- **硬/软记忆拆分（v0.1 修订：架构对齐 ADR-003）**：
  - **硬记忆**（叛逃 BETRAYAL / 灭国之仇 / 通缉名单）：结构化表**确定性注入** prompt，不依赖检索、绝不遗忘、绝不"装作无事"；跨赛季全量保留。硬人设承诺（"韩君最记仇"）不能靠概率召回——漏注入一次即击穿支柱一。
  - **软记忆**（恩/怨/氛围/对话质感）：摘要 + 向量检索（RAG），摘要由旬度批处理流水线生成并双审。
- 记录类别：**叛逃**（硬，永久跨季）、**恩**（软）、**怨**（软）、**承诺**（硬：AI 必须履约或"背约记账"）、**重大事件摘要**（旬级压缩）。
- **释怀状态机（v0.1 修订新增）**——防恩怨只增不减污染 prompt：
  1. **时间衰减**：软记忆 intensity 每旬 -0.05 × 1/人格 `grudge_sensitivity`（韩 1.5 → 衰减最慢，记仇人设保持）；intensity < 0.2 且 4 旬无新事件 → 转"淡忘"，退出确定性注入、仅 RAG 可及。
  2. **和解事件**：对象做出补偿行为（超额军功/护送/献策解困）→ intensity 直接 -0.3，状态转"缓和"；君主语录提及（"昔年之隙，今以功赎"）。
  3. **他国斡旋**：外交系统斡旋事件可使**国与国** GRUDGE 降级——文臣外交线（行人/相邦席位定策斡旋）的玩法接口 ▲（v0.2 修订：文武官职体系）。
  4. **容量治理**：每君主软记忆活跃条目 ≤ 50，超出时最旧/最低强度条目强制压缩为 EVENT 摘要行。
  5. **硬记忆例外**：叛逃事实**永不淡忘**；但其反应强度可走状态机：通缉（当季）→ 铭记（跨季仍提及/拒境）→ "负荆"特殊事件线（叛徒支付极重代价）可释怨（不再拒境，语录仍提旧事）——红线：永不装作无事发生。
- 召回策略：每次决策注入 top-K = 10 条（按 相关度×情绪强度×时近度 排序；硬记忆不占 top-K 名额、总是全量注入）；跨赛季保留硬记忆全量 + 软记忆"恩怨摘要"（每类压缩至 ≤ 500 字，GDD-0 八节跨季保留项）。
- 记忆写入规则：玩家行为事件 → 规则引擎判定是否入账（阈值防噪音，如普通任务完成不入账）→ 入账时打情绪强度分。
- **AI 记忆是独有戏剧性资产**：叛逃者被通缉、拒境、战场点名、诏书提及——由 M4 事件决策 + M8 检索共同实现。

### 4.4 任务潮加权规则（伪代码，v0.1 修订：架构对齐——两级架构）

```python
# ── 第一级：规则引擎（零 LLM，确定性产出任务池）──
def gen_task_pool(snapshot, persona):
    W = {dim: persona.style_weights[dim] / 100 for dim in DIMS}   # 人格偏置底数
    # 方略树长期修正（REV-WRITEBACK 修订：跨文档一致性，承 S2 v0.10 注记）：
    #   W[dim] *= fanglue_longterm_factor(dim)
    #   方略树推进状态经 M2 快照第①层国力仪表盘进入（每国每旬 1 行摘要），
    #   作为对应维权重底数的长期修正项——方略树不生成任务、不占任务潮配额。
    for dim, flag in snapshot.shortage_flags:
        if flag == "LOW":        W[dim] *= 1.5
        elif flag == "CRITICAL": W[dim] *= 2.5
    for topic, votes in snapshot.petition_tendency.top(3):        # 玩家倾向温和放大
        W[topic.dim] *= 1 + min(votes / petition_norm, 0.3)       # 上限 +30%
    for t in TASK_TYPES:                                          # 人格厌恶惩罚
        if t.tag in persona.player_affinity.despise: W[t.dim] *= 0.5
    W = cap_dim_share(W, max_share=0.40)      # 防主导策略红线：单维度占比 ≤ 40%
    #   战时模式（REV-004 修订，主理人批准）：该国 at_war 时
    #   cap_dim_share(W, max_share=0.60, exempt={"MILITARY", "LOGISTICS"})
    quota = 10 + (snapshot.player_cohorts.active_dau // 100)      # 活跃度修正数量
    return TaskPool(weights=W, quota=quota, templates=draw(W, quota))  # 确定性任务池

# ── 第二级：LLM 权衡（仅主推方向 + 叙事，引用任务池 ID）──
def llm_weigh_and_narrate(pool, persona, snapshot):
    picks = llm_choose_priors(pool, context=snapshot, persona=persona)  # 输出须为池内 ID
    assert all(p.id in pool.ids for p in picks)   # 结构校验：不得凭空造任务
    return TaskWaveDirective(pool=pool, priors=picks,
                             narrative=llm_edict_text(picks, persona))
```

| 国力系统 GDD-S2（规划中） | `get_nation_snapshot(lord_id)` | 五维现值/环比/短板标记 | **强依赖**：无国力数据则决策流水线降级为模板诏令 |
| 外交系统 | `push_diplomatic_events(lord_id, window)` | 诏令摘要/摩擦/会盟 | 强依赖：事件决策的触发源 |
| 玩家行为日志服务 | `query_aggregates(lord_id, xun)` | 完成率/上书倾向/分群 | 强依赖 |
| 历史引力配置 | `get_gravity_state(nation)` | 命题 ID/权重/进度 | 中依赖：缺失则引力层置空 |
| 摄政系统 | `submit_regent_proposal()` / `receive_ai_stance()` | 提案/AI 立场/威望裁定输入 | 强依赖（L4 场景） |
| 运营配置后台 | 人格卡热更/引力参数/GM 覆盖 | 配置项+审计日志 | 运营依赖 |

### 6.2 服务的下游系统（消费本系统）

| 系统 | 接口 | 数据 |
|---|---|---|
| 任务系统 | `TaskWaveDirective` | 任务潮需求单（类型/权重/数量/叙事包装） |
| 国力系统 | `DomesticAction[]` | 内政效果指令（明示于诏令） |
| 史书系统 | 决策记录 + 语录 + 跨季恩怨摘要 | 大事记/语录辑录素材 |
| 朝堂/摄政系统 | AI 立场分 + 反对理由文本 | 廷议仲裁输入 |
| 音频系统（远期） | 诏令朗读文本 | 诏书仪式感演出 |

### 6.3 与摄政系统的仲裁交互时序

```
摄政提案 ─→ M6 接收 ─→ 查恩怨账本+快照 ─→ 生成 AI 立场分(-5~+5)与反对理由(君心形式)
        ─→ 摄政系统执行廷议：摄政撤回 | 强行推行（威望值判定，属摄政系统）
        ─→ 结果回写 M8 恩怨账本（摄政政绩/君主态度）
```
本系统在仲裁中的输出是**立场与理由**，胜负判定与威望值扣除**不归本系统**（反目标 A4）。

### 6.4 不做越界

- 不直接修改国力数值（只发指令，效果由国力系统结算并公示）。
- 不直接向玩家推送任何消息（全部经诏令/任务/朝堂通道，保证单口叙事）。

### 6.5 透明日志隐私边界（v0.1 修订：架构对齐新增）

- **赛季内**：摄政行为、君主决策全链路（决策↔输入快照↔记忆引用↔输出）全国全程可查阅——透明复盘承诺不变。
- **跨赛季**：匿名化归档——玩家标识 pseudonymization（UID → "某卿"式匿名代号），自由文本与身份关联解除；证据链分级存储（热：决策摘要；冷：完整 prompt，仅审计权限可及）。
- **"留名史册"授权**：赛季末玩家可主动授权以自选史名保留于《本服史书》与下季归档——隐私合规转译为名垂青史仪式，正向引导授权率。
- 删号权：玩家删除账号 → 其标识自热存储移除、跨季归档中匿名代号保留但不可回溯关联。

## 7. MVP 裁剪

### 7.1 MVP 范围锚点（GDD-0 九节）

单服 3 国（秦/齐/楚）、2 位深度人格君主（秦、齐）、齐国摄政单国试点、简化三维国力（军事/经济/民生）、旬制决策+事件决策+结构化选项。

### 7.2 八模块 MVP 对照表

| 模块 | MVP 实现 | 砍掉/简化项 | 恢复时机 |
|---|---|---|---|
| M1 人格卡库 | 秦/齐 2 张完整人格卡（含全部字段） | 其余 5 国人格卡（按 GDD-0 4.1 表预置为"原型卡"占位，不作深度人格运行） | V1 |
| M2 决策输入聚合 | 四层输入中实装 3 层：国力（三维）、玩家行为聚合、事件流 | **历史引力层整体砍掉**（快照字段保留、置空） | V1 |
| M3 旬度决策流水线 | 完整实装（含批处理、降级模板诏令） | 七国同刻跑批→3 国；复盘语录简化为单条 | — |
| M4 事件触发决策 | 触发源缩至 3 类：宣战/停战、天灾、叛逃 | 会盟邀请、刺杀、复国宣战 | V1（复国宣战随复国线） |
| M5 任务潮生成 | 完整实装（含 40% 占比上限——主导策略红线不因 MVP 放松） | 任务类型池缩小至文事/武略基础类型（对应 MVP 文武官职最小版；v0.2 修订：文武官职体系） | — |
| M6 摄政干预接口 | 齐国单摄政位，权限限 2 项：任务潮优先级 + 威望值机制 | 廷议仲裁流程（冲突=威望不足直接否，无廷议演出）；战时动员节奏；俸禄比例；弹劾/次席 | V1 |
| M7 君心参悟生成 | 实装（双审简化为机器审+运营抽检 20%） | 追问式君心参悟（L3 君心追问砍掉） | V1 |
| M8 AI 记忆/恩怨账本 | 实装核心 3 类：叛逃（永久跨季）、怨、重大事件摘要 | 恩类细目、承诺类、君主-摄政信任动态 | V1（信任动态属远期） |

### 7.3 MVP 成本护栏（落地 G5）

- 自由对话场合 MVP 砍至 1 个（齐国 L3 朝堂对话试点，每日 3 次）；
- 预算熔断保留：单服日 token 预算上限（数值由架构对齐后定 ▲），超限 → 分级降级（限长→限频→模板化，见 §4.6）；降级话术采用**齐国人格"倦勤"模板最小版**（1 国 × 1 场合 × 3 级别，运营文案预写，v0.1 修订）；
- 旬度决策 3 国 × 每旬 1 次批处理，成本可测算。

### 7.4 MVP 验证对照（两个核心验证问题）

| 验证问题 | MVP 内的度量 |
|---|---|
| AI 君主是否让玩家感到"世界是活的" | 齐秦（深度人格）vs 楚（原型卡占位）三国的诏令阅读率、任务响应率、语录截图率对比 |
| 玩家摄政是否增强而非稀释体验 | 齐国（摄政试点）vs 秦楚（纯 AI 对照）的活跃留存、上书率、社群讨论量 A/B |

## 8. 验证指标

### 8.1 核心指标："君主是活的"量化验证

| 指标 | 定义 | 目标值（MVP 阶段） | 采集方式 |
|---|---|---|---|
| **人格盲测正确率** | 去标识诏令截图，玩家猜国正确率 | ≥ 60%（随机基线约 33%） | 每旬社群问卷（3 国期基线 33%） |
| **决策多样性指数** | 旬度国策诏目标类型的 Shannon 熵（同一君主跨旬） | 熵值 ≥ 1.2 nats，且相邻两旬目标重合率 ≤ 60% | 决策日志统计 |
| **短板-任务潮相关性** | 短板标记与旬内对应维度任务占比的皮尔逊相关 | ≥ 0.7 | 数据后台 |
| **行为连续性违规率** | 恩怨账本应有召回却被违背的决策次数 / 涉账决策总数 | ≤ 5%（季度回归测试+线上抽检） | 回归测试套件 |
| **恩怨账本健康度**（v0.1 修订新增） | 活跃软记忆条目 ≤ 50/君主；季释怀率（淡忘+缓和 / 总软怨类条目）≥ 20% | 超限说明账本单调膨胀，须查衰减与和解事件触发率 | 决策日志统计 |
| **旬诏-事件冲突感知**（v0.1 修订新增） | 被覆盖旬诏条目的"已因时事更易"说明打开率 | ≥ 60%（低于此说明覆盖规则破坏玩家对旬诏的信任） | 埋点 |
| **语录截图率** | 含君心语录的游戏内截图分享数 / 诏令阅读 UV | ≥ 1.5% | 埋点+社群爬取 |
| **君心学讨论热度** | 社群"猜君心/解读诏令"主题帖数/周 | 首月 ≥ 10 帖/周且趋势为增 | 社群监测 |
| **诏令阅读完成率** | 诏令打开→读完全部条目的比例 | ≥ 70%（低于此说明诏书沦为通知） | 埋点 |
| **上书-反馈闭环感知** | 上书玩家中"感到被君主听见"问卷得分（5 分制） | ≥ 3.8 | 月度问卷 |

### 8.2 护栏指标（不能变差的东西）

| 指标 | 阈值 | 说明 |
|---|---|---|
| 单服日 token 成本 | ≤ 预算上限（▲与架构对齐） | 超限触发熔断降级并告警 |
| 旬度决策准时率 | ≥ 99% | 降级模板诏令也计"准时"，但另计降级率（目标 ≤ 5%） |
| 合规违例语录 | 0（入库前拦截） | 任何线上违例语录为一票否决事故 |
| 人格回归偏差 | 季度重放 20 条固定输入，决策倾向偏差 ≤ 15% | 人格漂移防线（GDD-0 风险 1） |
| 降级期 L3 周留存降幅（v0.1 修订新增） | 触发 D1-D3 降级期间，受影响 L3 玩家周留存环比降幅 ≤ 10% | 超限说明"倦勤"叙事包装失效，须复盘降级话术与"国库用度"透明度 |

### 8.3 采集与复盘机制

- 每旬决策快照（M2）+ 决策输出 + 语录全部落盘 → 构成"君主决策回放库"，供回归测试、玩家复盘（透明日志）与史书生成三用。
- 每赛季末出《君主行为审计报告》：多样性/连续性/成本三张表，作为下季人格卡调参依据。
