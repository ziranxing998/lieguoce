# GDD-S10 · 个人开发者成本约束重构

> 文策渊 · SYS-S10 · 现实约束重构（**优先于此前一切范围决策**）
> 触发：用户明确"个人开发者，负担不起高额运营费用"——本文件重裁 MVP 为 MVP-0，并确立成本敏感设计原则（项目铁律之二）
> 成本数字为经验假设，**待 ARCH-008 校准**（程基岩）

---

## 一、成本敏感设计原则（项目铁律之二，v0.8）

> 个人开发者运营，**每个系统必须证明其运营成本可负担**。五条子原则：
> ① **立项即算账**：系统 GDD 必须附月运营成本估算（含 /CCU 边际成本）；无成本账不立项。
> ② **弹性参数**：所有与 CCU 挂钩的 LLM/服务器成本参数——旬长、对话配额、君主数、任务池规模、限频、事件决策频次——必须可调，且每个参数预设"降档位"（如配额减半开关）。
> ③ **生成优先**：内容生产（任务模板/语录库/人格语料/降级话术）优先 LLM 生成管线自动产出+抽样人工终审（5-10%），人工不写初稿，只把红线。
> ④ **BYO 优先**：能由玩家自付的能力优先外部化（客卿=玩家自付 LLM，是全项目最大成本外部化设计）。
> ⑤ **成本透明延续**："国库用度"半透明叙事（S1 §4.6）不变——成本治理留在世界观内，个人开发者与玩家的信任靠公开维系。

## 二、MVP-0 重裁（个人开发者可行版）

**目标**：CCU 30-100 的单服（3 国 × 人均 15-30 人）；开发周期 16-24 周（个人节奏）。

### 逐项对比：原 MVP → MVP-0

| 项 | 原 MVP | MVP-0 | 变更理由 |
|---|---|---|---|
| 规模 | 单服 3 国（团队运营假设） | **3 国 × 人均 15-30 人，CCU 30-100** | 现实约束 |
| **旬长** | 现实 3 天 | **现实 7 天** | LLM 决策成本 ÷2.3；低人口下任务潮需要更长窗口积累响应；玩家生活节奏友好 |
| 君主 | 2 深度（秦/齐）+ 楚原型卡 | **不变（保留 A/B）** | 核心卖点验证，不砍 |
| 文武官职 | 八档散阶+每国 2 席位（数据驱动） | 不变（数据驱动成本≈0） | 核心循环 |
| 国力/归因/上书 | 三维+归因链最小版 | 不变 | 玩法脊柱 |
| 会战 | 一场完整会战（36h 窗口） | 保留，窗口缩至 **24h** | 低人口集结更快收敛 |
| 事件决策 | 3 类触发源 | **2 类：宣战/天灾**（叛逃并入宣战檄文叙事） | 每类触发源=独立校验与测试面 |
| 内容生产 | 人工撰写模板库（文策资产清单） | **LLM 生成管线+5-10% 抽检** | 最大开发成本项之一被管线化 |
| 摄政试点 | 齐国 1 席、2 权限+威望 | 保留不变 | 差异化验证核心 |
| 外交 | 斡旋临时规格 | 保留不变 | 已最小 |
| 透明日志 | 全国全程可查阅 | **降级：本人可查 + 月度公开摘要** | 存储与隐私治理成本大降，V1 按收入恢复 |
| 史书生成 | 季末自动生成 | **季末半自动**（LLM 初稿+本人终审，可延后一周） | 一次性批处理，成本小但省心 |
| LLM 网关 | 双供应商热切换+计量熔断 | **单供应商+备用 key，薄封装**（计量与熔断保留——这是成本安全带） | ADR-001 简化 |
| 消息总线 | NATS JetStream | **单进程模块化事件队列**（接口按总线语义设计，NATS 延后） | 待 ARCH-008 确认 |
| GM 工具 | 配置文件+审计 | 不变（GM=开发者本人） | — |
| 客卿 | MVP 砍（字段位预留） | 不变 | — |

## 三、成本优势盘点（项目已有的省钱设计——强化而非新建）

| 既有设计 | 节省机制 | MVP-0 强化动作 |
|---|---|---|
| **客卿 BYO**（玩家自付 LLM） | 高级 AI 玩法成本外部化，官方零边际 | 维持 V1 内测节奏不变；宣传主打"自带 AI"差异点 |
| 旬决策批处理（Batch API 5 折） | 核心决策成本可忽略量级 | 旬=7 天进一步 ÷2.3 |
| 结构化选项为主 | 自由对话仅 ≤5% 玩家；配额+熔断分级 | 齐国单场合试点不变；D1-D3 降级保留 |
| 模板化君主（楚原型卡） | 第三国零深度调优成本 | 不变 |
| 任务潮规则引擎（零 LLM） | 任务供给零边际成本 | 不变；模板由生成管线产出 |
| 守舍报告/旬度报告拉取模式 | 离线内容聚合推送，无长连接开销 | 不变 |
| "国库用度"半透明 | 成本治理转世界观叙事 | 上线即开（个人开发者与玩家共担信任） |
| 生成管线（③原则） | 内容资产人工成本→电费 | **新增**：MVP-0 开发期建 1 条通用生成管线（prompt 模板+批量跑+抽检队列），覆盖任务模板/语录库/降级话术/人格语料四类资产 |

## 四、收入与扩容路线（三档月成本场景）

**假设口径**：LLM=主流中档商业模型（Batch 5 折用于旬决策）；基础设施=单 VPS 自托管 PG+Redis（进程内队列）；数字为经验值，**待 ARCH-008 校准**。

| 档位 | CCU | LLM/月 | 基础设施/月 | **月总成本** | 主要敏感变量 |
|---|---|---|---|---|---|
| 起步 | 30 | ~$10（旬决策 <$3 + 齐国对话 ~$7） | ~$25（轻量 VPS+域名备份） | **≈ $35** | 对话次数 |
| 目标 | 100 | ~$40（对话线性增长为主） | ~$50（升配+自动备份） | **≈ $90** | 对话次数 × 上下文长度 |
| 上限 | 300 | ~$120 | ~$120（升配+监控+扩存储） | **≈ $240** | 此时须触发降档位或开收费 |

**收入解锁路线**（按月收入解锁 V1 范围，避免一次性扛全量成本）：
1. **MVP-0 期**：免费+爱发电/众筹（覆盖 $35-90/月即健康）；"国库用度"页公开成本=众筹叙事。
2. **小额收费**：士籍月卡（定价覆盖边际成本×安全系数）；解锁：透明日志全国查阅恢复、对话配额上调。
3. **月收入 >$300**：启动 V1 扩容（7 国全人格、完整廷议、外交全动作、客卿全量）——每项扩容先出成本账再动工（原则①）。

## 五、可以砍 / 必须留

### MVP-0 砍/降级清单（相对原 MVP）
- 透明日志全国查阅 → 本人可查+月度摘要（V1 收入解锁恢复）
- 史书自动生成 → 季末半自动
- 双供应商 → 单供应商+备用 key（网关薄封装）
- NATS → 进程内事件队列（接口按总线语义，可平替）
- 事件决策 3 类 → 2 类
- 人工内容资产 → 生成管线（这是"替代"而非"砍质量"——红线抽检保留）

### 绝不能砍（砍了就不是《列国策》）
- **AI 君主人格与旬决策**（含君心语录/复盘连责）——支柱一的根
- **文武官职核心循环**（定策-执行-归因-声望）——支柱三的根，且已是最小实现
- **A/B 对照结构**（秦齐深度 vs 楚原型）——核心卖点的验证器
- **摄政齐国试点**——差异化卖点验证器
- **客卿 BYO 框架与字段位**——最大成本外部化设计，schema 冻结前必须预留
- **计量熔断（D1-D3）与"国库用度"透明**——成本安全带，个人开发者的生存装置
