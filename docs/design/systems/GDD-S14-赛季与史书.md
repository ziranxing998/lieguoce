## 1. 系统概述

**一句话**：赛季与史书系统是《列国策》的**时间之神与史官**——它掌管赛季日历（旬号推进、季末触发）、结算流水线（冻结→评定→折算→重置→发榜）、史书生成管线（素材收集→LLM 撰史→人工抽检）与跨季保留账（声望遗产/君主记忆/恩怨归档），让每 12 旬一次的"改朝换代"成为玩家资产的安全交接仪式，而非删档重来的惩罚。

> **定纲原则（本 GDD 第一命题）**：**赛季重置不是删档，是改朝换代。** 世界（国力/版图/战事/外交）被时间冲刷，**人（声望/履历/恩怨/家族/史名）穿越王朝延续**——玩家在旧朝积累的一切"名"都在新朝得到承认。

**在整体中的位置**：
- 它是支柱二"国运涌现"的**收束与再出发**：一季玩家集体行为涌现的国运，季末被评定、被写成史书、被讲述——"架空"因史书而成为可讲述资产而非损失（GDD-0 风险 5 缓解）。
- 它消费**所有系统的季末输出**：S2 结算快照（N6）、S1 决策回放库（§8.3）与跨季恩怨摘要（M8）、S4 灭国/复国终局（X8）、S5 遗产折算（§4.6）与名臣 Top10（P6）、S8 摄政列传——本系统是全 GDD 队列的**汇流口**。
- 它**不评定**数值口径（S2 定义五维与快照）、**不折算**遗产公式（S5 §4.6 定义，本系统执行触发）、**不撰写**决策（史书素材全部来自各系统已归档记录）。

```
[S2 N6 结算快照] ─┐
[S1 M8 恩怨摘要/回放库] ─┤
[S4 X8 灭国终局]  ─┼─→ 【GDD-S14 赛季与史书】 ─→ 史书公示（全国）
[S5 P6 遗产/Top10] ─┤         │        ├─→ 跨季保留账（遗产/记忆/归档）
[S8 摄政列传]     ─┘         │        └─→ 新季重置（参数下发各系统）
                        [赛季状态机 SEASON ACTIVE→SETTLING→RESET]
```

## 2. 设计目标与反目标

### 目标（按优先级）

| # | 目标 | 验证方式 |
|---|---|---|
| G1 | **改朝换代感**：季末结算被玩家体验为"史诗收官+新朝开局"，而非清档重来 | 季末问卷"期待新赛季"≥ 3.8/5；跨季留存（下季首旬回归率）≥ 上季均值 90% |
| G2 | **人穿越王朝**：声望遗产/恩怨记忆/史名在跨季 100% 兑现且可感知 | 遗产领取率 ≥ 90%（S5 G5）；遗产玩家次季首旬活跃/新玩家 ≥ 1.3（S5 §8.1 复用） |
| G3 | **史书可讲述**：史书产出被玩家阅读、引用、传播——"我们那一代玩家阻止了秦统一"的载体 | 史书阅读率 ≥ 40% 活跃玩家；史书截图/引用率可观测 |
| G4 | **结算确定性可审计**：评定/折算/重置全部确定性规则、零 LLM、可复盘 | 结算流水线可追溯率 100%（工程验收） |
| G5 | **成本可预算**：季末 LLM 消耗集中在史书撰史的**每季一次批调用**，量级可预估入月度账 | 季末结算 LLM 成本 ≤ 月预算 15% ▲（与 ARCH-008 联测） |

### 反目标（本系统明确不做的事）

| # | 反目标 | 理由 |
|---|---|---|
| A1 | **不做删档式重置**：除"确定性重置清单"（§3.5）外的任何玩家资产不得季末蒸发——重置清单之外的遗留数据视为事故 | 第一命题"改朝换代不是删档"；资产丢失=一票否决事故（对齐 S4 A1"流亡不删号"同精神） |
| A2 | **不做结局剧本**：评定规则全透明公示（版图/存续/国力权重公开），无隐藏结局、无 GM 内定"剧本走向" | 支柱二"涌现"：结局必须由玩家行为+透明规则产生；历史引力参数 GM 可调但**公开可查**（GDD-0 §八） |
| A3 | **不做全自动史书**：史书 LLM 生成后必经抽检（MVP 人工终审 100%，正式版 5-10% 抽样）才发布 | 史书是长期留存的核心资产，一次事故文案（人格崩坏/现代语/合规违例）污染整季记忆 |
| A4 | **不跨季泄露个体隐私**：跨季归档一律匿名化（UID→"某卿"代号），"留名史册"须玩家主动授权（S1 §6.5） | 隐私合规红线；名垂青史是仪式不是默认 |
| A5 | **不在赛季中改规则**：换算权重（S5 §8.2）、评定权重、重置参数赛季内冻结，只可季间调（带审计+回归） | 赛季中改规则=公平性事故 |

## 3. 系统拆解（6 子模块）

| 模块 | 职责 | 输入 | 输出 |
|---|---|---|---|
| H1 赛季日历与状态机 | 旬号推进、SEASON_LEN 计季、季末触发结算 | 全服时钟 | 赛季状态（→ 全系统） |
| H2 结算流水线 | 冻结→评定→折算→重置→发榜 五步批处理 | 各系统季末输出 | 结算结果/重置指令/发榜公示 |
| H3 史书生成管线 | 素材收集→LLM 撰史→抽检→发布 | 决策回放库/事件包/列传 | 《本服史书》 |
| H4 跨季保留账 | 四分类账（全量保留/压缩归档/匿名化/确定性重置）的核对与执行 | H2 产出 | 保留账清单（审计用） |
| H5 新季参数器 | 霸主加成、初值重置、史痕开局、引力重调 | 评定结果、GM 配置 | 新季开局参数包 |
| H6 史书展示与考据 | 史书阅读界面、考据玩法入口、授权仪式 | H3 产出、玩家授权 | 史馆 UI |

### 3.1 H1 赛季日历与状态机

- **赛季长度**：`SEASON_LEN = 12 旬`（试玩版继承）。参数化声明 ▲：SEASON_LEN 为 GM 可调弹性参数（铁律二②）——MVP 旬=7 天时一季 12 周（落在 GDD-0 §八"8-12 周"区间上限）；V1 旬缩至 3 天时一季 5 周，或调 SEASON_LEN=20-28 旬（成本账先行：季末结算与史书成本与旬数无关、与国数线性）。
- **状态机**：

```
SEASON_ACTIVE ──末旬结算点──→ SETTLING（冻结批处理窗口）
   ↑                            │ 评定/折算/史书/重置 全流水线
   └──── RESET ────发榜完成─────┘
（历史赛季 → ARCHIVED：匿名化归档，史书永久可读）
```

- **结算触发**：末旬（x12）结算点自动触发；GM 可手动延迟一旬（异常处理，带审计公告"天命未定，再加一旬"——人格化叙事包装）。
- 旬号与赛季号全局唯一键：`(season_id, xun)`——全系统快照/归档/回放的统一坐标（对齐 S1 决策按"旬号+序号"版本化的上级坐标）。

### 3.2 H2 结算流水线（五步批处理，零 LLM 直至史书步）

**第 1 步 · 冻结**：末旬结算点冻结全服状态——五维终值（S2 N6）、席位/摄政在任表、未决廷议（EXPIRED 归档）、进行中会战（强制 SETTLED，按当前节点判定战果）、上书/议政案未裁项（ARCHIVED 不罚，对齐"覆盖不罚"精神）。冻结即出 `settlement_snapshot_id`。

**第 2 步 · 评定**（确定性规则，权重公示）：
- **国力评定**：五维总和排序（试玩版口径继承）→ 季度国势榜；
- **存续评定**：ACTIVE / FALLEN（S4 X8：以灭国时点国力曲线参评）/ RESTORED（记复国史痕）/ ANNEXED（版图并入，叙事封存入史馆）；
- **人物评定**：Top10 策功/事功（S5 P6）→ 名臣列传提名；摄政政绩 → 摄政列传（S8）；"失印"/弹劾史痕 → 史书人物条目。
- MVP 权重：国力总和 100%（版图项 V1 引入，S4 Q5 的史痕开局一并 V1 落地 ▲）。

**第 3 步 · 折算**（跨季保留账，见 3.4/H4）：S5 §4.6 遗产公式执行、恩怨摘要压缩、匿名化归档。

**第 4 步 · 重置**（H5 新季参数，见 3.5）：确定性重置清单执行 + 新季参数包下发。

**第 5 步 · 发榜**：史书公示 + 新季开启事件（"史册已定，列国重开"——试玩版 `last_event` 继承）+ 遗产就位通知（遗产玩家登录可见"先朝功业折算"清单）。

### 3.3 H3 史书生成管线（素材收集 → LLM 撰史 → 人工抽检）

**素材收集**（全部来自已归档数据，零额外记录成本）：
| 素材 | 来源 | 用途 |
|---|---|---|
| 旬曲线与终值 | S2 N6 | 国势章节、评定依据 |
| 国策诏+君心语录全辑 | S1 回放库（§8.3 决策回放库三用之史书用） | 语录辑录、君主性格叙事 |
| 恩怨大事记 | S1 M8 EVENT 摘要 | 恩怨章节（叛逃/和解/负荆） |
| 灭国/复国事件包 | S4 X7 叙事素材包 | 灭国史诗/复国史诗独立章节 |
| 摄政列传/失印史痕 | S8 | 共治章节 |
| Top10 名臣归因链 | S5 P6（对接"留名史册"授权） | 名臣列传 |
| 廷议归档/议政案采纳录 | S13 | 朝堂风云章节（选摘） |

**LLM 撰史**（每季一次批调用，成本 G5）：
- 试玩版最小版继承：太史令人设 prompt，"文风仿《史记》本纪末尾'太史公曰'，点评列国兴衰"——【勘误/升级】试玩版单条 80 字史书升级为**章节化生成**：太史令曰（总评）→ 国势志（列国兴衰）→ 名臣列传（Top10，授权者记名/未授权者匿名代号）→ 恩怨/战纪选辑；每章独立 prompt、共享素材包、独立模板兜底。
- **模板兜底链**：LLM 失败/超时 → 按评定结果参数化模板（试玩版 fallback 模板升级为章节模板库）——**保证每季必有史书**（与 S1"每旬必有国策诏"、S12"每旬必有差事"同构的节奏承诺）。
- **抽检**：MVP 人工终审 100%（个人开发者季更节奏可负担）；正式版机器审（合规+文风禁词表，S1 M7 同管线）+ 人工抽检 5-10%（铁律二③）。
- 合规红线：史书对真实历史人物仅作背景引用、对玩家行为只述"名"不述可识别个人信息（对齐 A4）。

**发布**：史书入史馆（H6）+ 全服公示事件；ARCHIVED 赛季史书永久可读。

### 3.4 H4 跨季保留账（四分类，A1 的正面清单）

| 分类 | 内容 | 规则 |
|---|---|---|
| **全量保留** | 玩家声望遗产（S5 §4.6 折算：遗产分=0.5×峰值+0.3×功过+0.2×席位旬×50，初始档位按门槛就位、初始声望=遗产分×0.5）；履历档案；家族谱系；硬记忆（叛逃/灭国之仇，S1 M8 跨季全量）；身份牌史痕 | 折算公式属 S5，本模块执行触发并出**保留账清单**（玩家可在史馆核对"我的什么留下了"） |
| **压缩归档** | 软记忆恩怨摘要（每类 ≤500 字，S1 M8）；摄政列传；廷议归档；决策回放库（冷存储：热=决策摘要、冷=完整 prompt，S1 §6.5） | 压缩规则由源系统定义，本模块核对完整性 |
| **匿名化** | 跨季归档中玩家标识 UID→"某卿"代号；自由文本与身份解除关联；"留名史册"授权者保留自选史名（授权仪式在 H6） | S1 §6.5 全文适用；删号权：热存储移除、归档代号不可回溯 |
| **确定性重置** | 五维国力（回初值 40+霸主加成，试玩版继承）；旬号（回 1）；战事/方略/外交矩阵（试玩版 `war_*/fanglue/diplo` 清空继承）；席位/摄政/威望（威望不结转，S8 R4）；廷议议程/上书格位/推举票；历史引力进度（GM 重调） | 重置前逐项出清单、重置后逐项核销（工程验收：清单外遗留=0） |

- **按国隔离重申**（S5/S4 定稿）：遗产与履历按国隔离——换国者遗产留原国，原国复国/回归时恢复；流亡者按流亡期表现计遗产（S4 X8）。
- 【勘误/升级】试玩版"声望作为跨季遗产保留"（prestige 数值原样带入新季）为最简版遗产——正式版按 S5 §4.6 公式折算（峰值+功过+席位三因子），并给**初始档位就位**而非纯数值延续——试玩版语义是其**语义子集**（REV-WRITEBACK 修订：跨文档一致性——精确化：声望延续语义由公式峰值项承载，实际兑现系数为 0.5×0.5=**0.25×峰值**；试玩版为 1.0×峰值原样带入，数值上高于正式版声望延续项，"初始档位就位"为对冲的隐性价值——**遗产清单页须明示折算规则，防"声望缩水"感知**），平滑升级无需数据迁移。

### 3.6 H6 史书展示与考据玩法

- **史馆 UI**：卷轴形态（视觉锚点②），章节目录+正文；历季史书并列可读——"翻开上一朝的历史"是跨季情怀的核心入口。
- **考据玩法（君心学的史书形态）**：语录条目可展开"考据"视图——玩家可对照透明日志（赛季内）查语录背后的决策依据（S1 §4.5 暴露规则内）——史书不是虚构文学，是**可考据的信史**，这是"涌现可讲述"的硬支撑。跨季归档匿名化后，考据保留"事"不保留"人"。
- **留名史册仪式**：季末人物评定后，玩家收到"太史请名"请求——授权则自选史名入列传（授权率是 G3 伴生指标）；未授权者以"某卿"入列传但事迹如实记录。
- **复国史诗/灭国史诗**：独立章节+全服推送事件卡（V1 完整版；MVP 模板化一句话）。

## 4. 数据规格

### 4.1 赛季状态机 schema

| 字段 | 类型 | 示例值 | 说明 |
|---|---|---|---|
| `season_id` | string | `"s1"` | 全局赛季坐标 |

## 5. 玩家交互流程（三视角）

| 视角 | 关键路径 | 体验要点 |
|---|---|---|
| **全玩家** | 末旬"天命将定"预告 → 季末史书发布推送 → 史馆读史（本季+历季） → 新季开启事件 → 首旬朝会 | 史书发布是**全服共同时刻**（试玩版 toast"本季史书已修成——列国重开"规格化为全服事件卡）；读史即读"我们做过的事" |
| **有遗产玩家** | 登录见"先朝功业折算"清单（遗产分三因子明细，S5 公式透明） → 初始档位就位 → 首旬以中大夫入朝（而非下士重爬） | 折算清单逐项可查（G2/G4）；"你的旧君还记得你"——硬记忆条目在新季诏书中自然再现（S1 M8） |
| **上榜者/被记载者** | "太史请名"授权 → 史名入列传 → 史馆 permanent 可读 → 次季他人考据引用 | 名垂青史是**主动授权的仪式**（A4）；未授权者的"某卿"代号同样事迹如实——荣誉给事，不强迫给人 |

**关键体验时刻**：
- **太史令曰**：每季一句总评，是全服社群的"季末金句"（截图率核心素材）；
- **改朝换代瞬间**：发榜事件卡以"史册已定，列国重开"八字开场（试玩版继承），配合水墨卷轴翻页演出（V1）——重置的"失去感"被史书的"留存感"对冲。

## 8. 验证指标

### 8.1 核心指标

| 指标 | 定义 | 目标值 | 采集 |
|---|---|---|---|
| **跨季留存**（G1） | 下季首旬回归玩家 / 上季末活跃玩家 | ≥ 70%（首季基线，逐季对标） | 分季对比 |

| **史书阅读率**（G3） | 阅读≥1 章的活跃玩家占比 | ≥ 40% | 史馆埋点 |
| **史书传播** | 史书截图/引用（含社群）次数/季 | 首季 ≥ 10 次且逐季增 | 埋点+社群监测 |
| **留名授权率** | 上榜者中授权史名比例 | ≥ 50%（过低=仪式感失败；过高复核授权流程是否被默认勾选） | 授权日志 |

| **结算准时率** | 季末结算在批处理窗口内完成率 | 100%（延迟须有 GM 审计） | H1 状态机 |
