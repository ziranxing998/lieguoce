## 1. 系统概述

> **v0.9 注记（联动 GDD-S11 大容量服务器与玩家分层）**：国力五维是 AI 君主决策输入第①层（GDD-0 §4.2）。大容量场景下本系统作为**分层统计聚合的出口之一**——输出口径恒为"按国聚合的五维值+旬环比+短板方向"，玩家个体贡献只进聚合计算、**不逐条进君主 prompt**；聚合粒度与容量表见 GDD-S11 §4，本系统接口不变。
>
> **v0.10 注记（文明系参考）**：**「方略树」= 国力长期驱动线之一**（文臣推动、一旬推进一格、全国共享收益，转译方案见 GDD-0 §五"文明系玩法内核转译"）——方略树格子的收益**走本系统既有归因链入策功**，并抬升对应维的长期收益曲线与任务潮权重底数；**不生成任务、不占任务潮配额**（方略树=国家级长期线，任务潮=旬级短期潮，职责分离防冲突）。接口：方略树推进状态并入第①层国力仪表盘，以每国每旬 1 行摘要呈现（token 恒定，随 GDD-S11 聚合口径走）。

**一句话**：国力五维系统是《列国策》世界的"物理引擎"——它定义并结算军事/经济/文化/民生/外交五维数值，把玩家的任务执行与文臣方略按收益声明与递减规则聚合为国力变化，维护策功/事功双轨归因账本，检测短板并触发任务潮，最终为 AI 君主引擎、摄政考评与赛季史书提供唯一权威的国力数据源。

**在数据流中的位置**：

```
[S1 AI 君主引擎] ──任务潮需求单/诏令目标(含提案引用)──→ 【GDD-S2 国力五维】←──任务收益结算事件── [任务系统]
        ↑                                                      │
        └── 国力快照(五维/环比/短板) ── M2 决策输入            ├─→ 归因账本 → 恩怨账本(策功/策罪入账)
            短板触发任务潮(经 S1 M5)                           ├─→ 摄政系统(策功/事功政绩口径)
                                                              └─→ 赛季史书(国运结局评定素材)
```

- 它**不生成**任务（消费 S1 需求单与任务系统结算事件）、**不决策**（只向 S1 供数）、**不裁决**声望与官职（归因账本只产出"国力变化归因"，声望换算属官职/声望系统）。
- GDD-0 支柱二"国运涌现"的数值载体：玩家集体行为 → 本系统 → 国力/版图/结局，改变可量化、可归因、可讲述。

## 2. 设计目标与反目标

### 目标

| # | 目标 | 验证方式 |
|---|---|---|
| G1 | **联动可感知**：玩家任务/方略与五维变化的因果链玩家可亲眼追溯 | 归因面板打开率、归因可读性问卷 ≥ 3.8/5 |
| G2 | **防主导策略红线**（GDD-0 §六）：单一维度收益递减、任务池维度占比 ≤40%、刷量边际收益趋零 | 递减后行为转移率 ≥ 40%；同维任务集中度监控 |
| G3 | **归因可信**：策功/事功归因链全程透明可复盘（对齐透明日志原则） | 归因链可追溯率 100%（工程验收） |
| G4 | **赛季可结算**：国力快照支撑赛季结局评定与史书生成 | 结算快照完整率 100% |
| G5 | **参数可调**：阈值/衰减/递减率全部 GM 可调，带审计 | 调参接口覆盖全部标定参数 |

### 反目标（本系统明确不做的事）

| # | 反目标 | 理由 |
|---|---|---|
| A1 | **不做实时平衡器**：不因"某国太弱/太强"暗中加减国力；AI 君主内政效果（S1 domestic_actions）是**明示于诏令**的少量温和行为，且计入归因 | 违反支柱二"涌现"；暗调必被玩家数据挖掘识破，摧毁信任 |
| A2 | **不隐藏归因**：任何国力变化必须有可查询的来源（任务/内政/衰减/事件） | G3 与"君臣共治"信任基础 |
| A3 | **不做玩家间国力转移**：国力不可赠送/交易/代充（玩家只能通过任务与方略贡献国力） | 防工作室与"国力倒卖"经济外挂 |
| A4 | **不拥有声望/官职**：本系统输出归因数据，策功→声望→官阶的换算属官职系统 | 职责单一；换算规则调整不该动国力结算 |
| A5 | **不做实时逐秒结算**：收益结算收敛到旬度批处理（实时只做展示层预估） | 与旬制决策节拍一致；批处理价成本可控（对齐架构基线） |

## 3. 系统拆解（7 子模块）

| 模块 | 职责 | 输入 | 输出 |
|---|---|---|---|
| N1 五维指标定义与构成 | 五维的子指标、上限、旬自然衰减定义 | 运营配置 | 维度数值与构成明细 |
| N2 任务收益声明与结算 | 任务发布时声明收益类型/量级；完成时结算入账 | 任务系统结算事件 | 维度增量事件（带任务 ID） |
| N3 策功/事功双轨归因账本 | 提案↔诏令目标↔国力变化的归因链；策功/事功记分 | N2 增量事件 + S1 诏令目标结构 | 归因记录、策功分/事功分（交声望/摄政/恩怨账本） |
| N4 收益递减引擎 | 单玩家单维旬内递减；防刷聚合 | N2 增量事件 | 结算前修正（递减后实际收益） |
| N5 短板检测与任务潮触发 | 三级短板判定；短板→S1 任务潮触发的通知 | N1 维度现值 | 短板标记（进 S1 快照）；触发通知 |
| N6 赛季结算快照 | 赛季末冻结五维终值与全程曲线 | N1/N3 | 结算快照（交史书/跨季遗产） |
| N7 GM 调参接口 | 全部标定参数热更+审计 | 运营 | 参数版本（对齐人格卡 gm_overrides 模式） |

### 3.1 N1 五维指标定义与构成

| 维度 | 子指标构成 | 初值 | 上限 | 旬自然衰减* | 主要供给来源 |
|---|---|---|---|---|---|
| 军事 | 兵源、装备存量、要塞完好度 | 50 | 100 | -1.5/旬 | 武略任务、战果、武将督办 |
| 经济 | 城邑产出、商路通度、府库 | 50 | 100 | -1.0/旬 | 文事任务（商贸/物流）、商家式方略执行 |
| 文化 | 学宫声望、人才吸引力 | 40 | 100 | -0.5/旬 | 文事任务（探索/著述）、太史线 |
| 民生 | 人口、粮草储备、民心 | 45 | 100 | -2.0/旬 | 文事任务（劝农/赈济）、民生方略 |
| 外交 | 盟约数与质、朝贡关系 | 40 | 100 | -1.0/旬 | 文臣外交线、斡旋事件、会盟 |

\* **自然衰减标定依据**：民生衰减最重（无人力持续投入则粮耗民疲，先秦"足食足兵"逻辑）、文化最缓（学宫声望有惯性）——衰减保证"不作为的国必衰落"，是"国运涌现"的压力源，也是任务潮永不枯竭的供给泵。数值为首版建议 ▲可调。

- 上限 100 归一化（对齐 S1 §4.2 口径）；下限 0，归零即触发对应危机事件（民生归零→流民/叛乱事件流，交 S1 事件决策）。
- 七国**开局差异化初值**（秦高军事、齐高经济文化……）由赛季开局配置定，本表初值为通用基准。

### 3.2 N2 任务收益声明与结算

- **发布即声明**（GDD-0 §六）：任务实例须带 `declared_gain: {dim, base, quality_factor}`，玩家领任务时 UI 明示"护送粮队：民生 +X"。
- 结算三分制：`实际收益 = 声明基准 × 质量系数（完成度/时限/失败惩罚） × 递减修正（N4）`。
- 结算事件落事件溯源总线（对齐架构 A 层 A5），旬度批处理聚合入账（A5）。

### 3.3 N3 策功/事功双轨归因账本（v0.2 文武官职体系的核心数据结构）

- **策功链**：`议政案(proposal_id, proposer, dims_target) → 诏令目标(goal_id, ref_proposal_id) → 增量事件(Σdelta, 归属维度) → 策功分`。详见 §4.4。
- **事功链**：`执行任务(task_id, executor, ref_goal_id) → 结算收益 → 事功分`。
- **策罪**：诏令目标在 2 旬归因窗口内净变化为负 → 生成策罪记录（入恩怨账本 SOFT 类，君主复盘语录问责的对端数据）。
- 归因窗口：诏令目标发布起 **2 旬**（超窗后该目标收益转为"常规任务收益"不再计策功）。
- 策功/事功分只做**归因记分**，声望换算与官阶晋升属官职系统（反目标 A4）。

### 3.4 N4 收益递减引擎

- 玩家级公式与参数见 §4.2；旬重置。
- 聚合防刷：同一设备/支付指纹簇计入同一递减序列（防小号矩阵），判定规则由风控系统供给 ▲。

### 3.5 N5 短板检测与任务潮触发

- 三级判定（§4.3，正式标定 40/25）。
- LOW/CRITICAL 变化事件推送 S1（进 M2 快照）；CRITICAL 首次触发额外生成一条"危机叙事事件"（如"仓廪告急"）供 S1 事件决策与君心语录引用——短板不只是数字，是戏剧素材。

### 3.6 N6 赛季结算快照

- 赛季末冻结：五维终值 + 全季旬曲线 + 归因账本摘要（Top 策功/事功玩家，对接"留名史册"授权机制）。
- 输出：史书结局评定素材（版图/存续/国力综合评定，权重属史书系统）、跨季声望遗产的履历加权输入（官职系统）。

### 3.7 N7 GM 调参接口

- 可调参数全集：短板阈值（40/25）、递减率 r、各维衰减、归因窗口、开局初值、任务池占比上限（读 S1 配置联动）。
- 每次调参带版本号+操作者+理由，写入审计日志；参数变更自动触发 S1 回归测试集重跑（防调参引发决策行为漂移）。

## 4. 数据规格

### 4.1 维度快照字段（对齐 S1 §4.2，此处为权威定义）

| 字段 | 类型 | 示例值 | 说明 |
|---|---|---|---|
| `dim_values` | object | `{military: 62, economy: 48, culture: 71, welfare: 39, diplomacy: 55}` | 五维现值（0-100） |
| `dim_trend_3d` | object | `{welfare: -8}` | 近 3 旬环比（%），含自然衰减与行为增量 |
| `dim_rel_rank` | object | `{welfare: 7}` | 七国相对位次（1=最强） |
| `shortage_flags` | array | `["welfare_CRITICAL"]` | 三级短板标记 |
| `dim_composition` | object | `{military: {troops: 54, arms: 70, forts: 61}}` | 子指标明细（归因面板展示用） |
| `decay_applied` | object | `{welfare: -2.0}` | 本旬已施加的自然衰减（可追溯，A2） |

### 4.2 收益递减公式（首版正式标定）

```
单玩家单维度旬内第 n 次同维收益：
    gain(n) = B × r^(n-1)          r = 0.7（首版标定）
    B = 任务声明基准收益 × 质量系数

旬重置（n 计数随旬清零）。
示例：B=2.0 → 第 1/2/3/4/5 次 = 2.0 / 1.4 / 0.98 / 0.69 / 0.48
（刷满 5 次仅得 5.55，而做满 5 个不同维任务可得 ~9.2 —— 全维分散收益高 66%）
```

- **r=0.7 标定依据**：r 过高（≥0.85）刷量仍有利可图；过低（≤0.5）惩罚感过重劝退专注型玩法。0.7 下第 5 次收益不足首次一半，与"任务池 40% 占比上限"（供给端）构成供需双端防刷。
- **战时条款（REV-005）**：该国宣战期间（S3 状态机 DECLARED→终局），**军功/军需类任务递减放宽为 r = 0.8**，其余维度维持 0.7；停战即恢复。豁免范围与任务池 60% 豁免（S1 REV-004）严格同口径（军事/后勤类）——**供需双端一致性**：供给端 60% 放开军需任务供给，玩家端 r=0.8 保证支前边际收益衰减放缓，两端同指军需类，不会出现"池里全是支前任务但玩家刷不动"的断裂；40% 红线对战时非豁免维度仍然有效。
- 递减对**策功不豁免**：刷出来的收益按递减后计归因——刷子拿不到体面的策功分。
- **（v0.4 注记）口径独立声明**：声望点（S5）与国力收益（本系统）是两套独立结算——S5 v0.4 权重再平衡（日常任务声望 0.5→0.9、单任务额度 1-3→2-5 点）**不改变任务收益声明基准 B 与国力结算**，无需联动调参。

### 4.3 短板三级阈值（正式标定 ✔，回填 S1 §4.2）

| 状态 | 条件（归一化 0-100） | 效果 |
|---|---|---|
| NORMAL | ≥ 40 | 无 |
| LOW | < 40 | 任务潮对应维度权重 ×1.5（对齐 S1 伪代码） |
| CRITICAL | < 25 | ×2.5 + 首次触发"危机叙事事件" + 君主语录倾向 |

- **40/25 标定依据**：① 归一化 0-100 下，40 ≈ 全维度均值（50）-1 个标准方差的运营安全线——低于它意味着该国已明显掉队；② 25 ≈ 极端失衡线，接近下限 1/4，任由发展 2-3 旬内可触危机事件，必须强干预；③ 与 S1 既有伪代码（LOW ×1.5 / CRITICAL ×2.5）完全一致，无需改码；④ 上线后按七国分布实测回调（护栏：每次回调须经 N7 审计+回归测试）。
- 双保险：绝对阈值（40/25）+ **相对位次**（连续 2 旬位列七国末位且差于末二位均值 15 分以上 → 强制 LOW），防"七国普遍低迷时无人触发"的阈值失效场景。

### 4.4 策功归因链数据结构

```json
{
  "proposal_id": "prop_han_x13_007",
  "proposer_id": "u_88231",
  "dims_target": {"welfare": "+3~+5"},
  "status": "ADOPTED",
  "edict_ref": {"xun": 14, "goal_id": "g1"},
  "attribution_window": {"from": "x14", "to": "x15"},
  "delta_events": [
    {"task_id": "t_99012", "executor": "u_10244", "dim": "welfare", "delta": 1.4}
  ],
  "net_delta": 4.2,
  "strategy_score": 42,
  "verdict": "MERIT"
}
```

| 字段 | 说明 |
|---|---|
| `strategy_score` | 策略分 = **K × Σ(w_维度 × 净增量 × 时效系数)**，量纲常数 **K = 10（REV-005 正式标定）**。推导：本节示例单目标净增量 4.2 × w 1.0 × 时效 1.0 = raw 4.2，× K = **42**，与示例值自洽。维度权重（军事 1.2 / 民生经济外交 1.0 / 文化 0.8）与时效系数（第 1 旬 1.0 / 第 2 旬 0.8）。**统一量纲声明：K 同样适用于事功/军功/军策功的归因记分**（S5 P2 换算引擎为唯一声望换算出口）；K 为纯量纲缩放常数，数据驱动实现，调整不改码 |
| `verdict` | MERIT(策功) / FAULT(策罪，net_delta<0) / VOID(窗口未满或目标被事件诏令覆盖——覆盖不罚，对齐 S1"已因时事更易") |
| `delta_events[].executor` | 同时记入执行者事功链——一份增量事件喂两条归因链，文武账本同源不出叉 |

### 4.5 归因分摊规则（v0.2 补标：ARCH-002 架构对齐——程基岩第 8 项）

方略对应的国力变化量归多少，按下述口径分摊（原则：**只归因方略自己带来的直接增量**）：

1. **入链范围**：仅"提案 → 诏令目标 → 该目标转译任务链"上的**直接增量**（delta_events）计入策功链。
2. **不入链项**（进入国力总账但 `source` 标记隔离，不进策功分）：
   - `source=AI_DOMESTIC`：AI 君主内政效果（S1 domestic_actions）——那是君主的功，不是文臣的功；
   - `source=DECAY`：旬自然衰减；
   - `source=EVENT`：天灾/会盟等事件效果；
   - `source=OTHER_TASK`：非本目标转译的其他任务收益；
   - `source=WAR_STRATEGY_EVENT`：**战时斡旋/战术卡事件（REV-005 新增，见第 7 条战时例外条款）**。
3. **多任务分摊**：一个诏令目标转译 N 个任务时，各任务按**各自结算的实际收益**（声明基准 × 质量系数 × 递减修正后）直接计入，无需再按声明权重二次分摊——递减已经在结算端完成公平化，归因端不做重复修正。
4. **多玩家分摊**：任务结算归属执行者（事功）；策功不按玩家分摊，整条方略的净增量归**提案人**（文臣对策略整体负责，包括转译任务的执行质量——策功与执行结果绑定正是文武互需的机制表达）。
5. **冲突约束**：一个任务实例至多绑定一个诏令目标（`ref_goal_id` 唯一），杜绝一鱼两吃式重复归因；若任务同时服务多个方略，由任务系统在生成时拆分实例。
6. **窗口边界**：归因窗口（2 旬）截止后的同目标收益转 `source=OTHER_TASK`，不计策功。
7. **战时例外条款（REV-005，显式声明与平时口径的并存关系）**：战争状态期间，S3 斡旋卡（成功避免的国力损失折算正增量）与战术卡（该节点后续推进度变化的 **20% 归因份额**）以**份额制**计入军策功链——这是"直接增量"口径在战时的**唯一例外**；平时（PEACETIME/集结期）份额制自动失效、回归直接增量口径。工程可辨性：份额制增量在 `delta_events` 中携带 `source=WAR_STRATEGY_EVENT` + `share=0.20` 字段，透明日志复盘时可区分两套逻辑。

## 5. 玩家交互流程与 UI 呈现要点

| 层级 | 接触面 | UI 呈现要点 |
|---|---|---|
| **L1 布衣** | 任务收益声明：领任务时看到"护送粮队 → 民生 +2"；递减提示（"今日劝农之功已领多次，粟米之利渐薄"——递减用先秦语感正向提示，非惩罚红字） | 收益声明以竹简标签形式钉在任务卡上（视觉锚点②）；递减提示必须出现**在领取前**而非结算后（预期管理） |
| **L2/L3 文臣** | 定策归因面板：议政案状态流转（待议→采纳→署名于诏→归因窗口→策功/策罪判定）；诏令"采某卿之议"署名链接直达面板 | 归因面板 = 一条"策-诏-效"时间线（提案原文→诏令目标→旬度国力曲线→净增量），全链可分享截图（自传播素材）；策罪同样公示（政治戏剧感） |

| **L4 摄政** | 政绩总账：策功/事功双口径实时汇总（摄政考评三重指标的数据源） | 与透明日志同入口，赛季内可查（对齐 S1 §6.5） |

## 8. 验证指标

### 8.1 核心指标

| 指标 | 定义 | 目标值 | 采集 |
|---|---|---|---|
| **防刷有效性** | 玩家旬内同维任务占比分布中位数 | ≤ 35%（供给端 40% 上限下的自然分布） | 结算日志 |
| **递减行为转移率** | 触发递减后下一旬转向其他维度的玩家比例 | ≥ 40% | 结算日志 |
| **五维均衡度** | 七国×五维标准化后的全服标准差带 | 旬均 σ ∈ [8, 18]：过小=趋同无聊，过大=失衡弃游 | 数据后台 |
| **短板-回升闭环率** | CRITICAL 触发后 2 旬内回升至 ≥40 的比例 | ≥ 60%（低于此说明任务潮泵失效或衰减过猛） | N5 监测 |
| **归因可读性** | "我能看懂我的行为如何改变国力"问卷（5 分制） | ≥ 3.8 | 月度问卷 |
| **归因面板渗透** | 文臣策功面板 / 武将事功面板周打开率 | ≥ 30% / ≥ 40%（武将频次高） | 埋点 |
| **策功-采纳转化** | 议政案被采纳率 | 10%-30% 带宽（全拒=上书无用感；全采=AI 无主见，破坏支柱一） | S1 联动统计 |

### 8.2 护栏指标

| 指标 | 阈值 | 说明 |
|---|---|---|
| 归因链可追溯率 | 100%（工程验收，缺口即事故） | 每笔国力变化必须能回答"从哪来" |
| 结算准时率（旬批） | ≥ 99% | 对齐 S1 旬节奏承诺 |
| 刷量聚集告警 | 同簇（设备指纹）同维收益占比 > 20% 即告警 | 风控联动 |
| 调参审计覆盖 | 100%（无审计的调参=配置事故） | N7 强制 |

## 附录 A · 跨系统参数首版正式标定（收敛此前"待 S2 统一标定"项）

### A1 自由对话配额（正式标定 ✔，对齐 S1 §4.6）

| 场合 | 标定值 | 标定理由 |
|---|---|---|
| L3 朝堂对话 | 每日 3 次 | 架构成本模型锚点（500 L3 × 3 次/日 ≈ 1500 次/日/服，< $50/日/服 量级）；"一日三见"有先秦君前奏对的典故质感 |
| 君心参悟追问 | 每日 2 次 | 追问上下文含语录（较 L3 短），成本低但属解读型玩法——频率过高会使"参悟"变"查表"，压低到 2 次保参悟的稀缺谜题感 |
| 摄政陈情 | 每旬 3 次（次席 1 次） | 陈情服务于旬制廷议节拍，随旬重置；3 次 ≈ 廷议 1 次发起+2 次预备沟通的实务量 |

### A2 恩怨释怀参数（正式标定 ✔，对齐 S1 §3.8）

| 参数 | 标定值 | 标定理由 |
|---|---|---|
| 软记忆时间衰减 | intensity 每旬 -0.05 × 1/grudge_sensitivity | 0.05/旬 → 中位君主（sens=1.0）一条怨从 0.8 衰至淡忘线（0.2）约 12 旬 ≈ 1 个赛季 8-12 周的 60%——"记一季"符合玩家记忆节拍；韩（1.5）约 18 旬，跨季仍记，人设成立 |
| 淡忘线 | intensity < 0.2 且 4 旬无新事件 | 0.2 = 8 分位弱情绪，低于此召回也不构成行为依据 |
| 和解减幅 | 单次和解事件 -0.3 | 一次大恩（超额军功）≈ 6 旬自然衰减的当量，"以功赎"要有可感知的分量但不至于一笔勾销 |
| 软记忆容量 | 活跃条目 ≤ 50/君主 | 对齐 prompt 预算：硬记忆全量+top-K10+软记忆 50 条的注入成本在人格卡缓存命中下可控（▲与 Q1 ADR 联测确认） |
| 归因窗口 | 诏令目标 2 旬 | 1 旬太短（旬中发布的方略来不及见效）、3 旬太长（策罪追溯过苛挫伤议政积极性） |

以上参数全部入 N7 GM 调参清单，线上按 A2 节奏（护栏指标）回调。
