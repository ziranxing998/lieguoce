## 1. 系统概述

> **v0.9 注记（联动 GDD-S11 大容量服务器与玩家分层）**：会战是全服最高并发场景。大容量设计原则——集结期操作（筹粮/造械/接取后勤任务）全部走**规则引擎零 LLM**，L1/L2 玩家贡献进聚合统计不逐条入 AI 上下文；LLM 仅承担宣战/停战决策与战后结算叙事（批处理）；兵符/节杖持有者恒为核心层玩家，随容量扩容其行为限频走 GDD-S11 容量表弹性参数（铁律二②）。
>
> **v0.10 注记（文明系参考）**：**节点战术选项 = 武将执行深度来源**（转译方案见 GDD-0 §五"文明系玩法内核转译"）——在节点攻防的会战窗口内增设**节点内离散战术决策**（列阵/断粮/夜袭/坚壁等），仅扩展武将指挥操作面，**不改节点推进制/集结期/结算状态机框架**；战术成败按军策功/军功对称归因（本文件既有 W 系列口径），限兵符/节杖持有者与临阵武将使用，客卿不得全自动代行（S7 会战约束"兵符统领类永不全自动"不变）；战术选项属会战窗口高频操作，走规则引擎+结构化选项（零同步 LLM），战术结算叙事并入战后批处理。

**一句话**：会战国战系统把"国与国的战争"从全天候乱斗改造为**节奏化的政治-军事大事件**——宣战（AI 终决）→ 2-3 天集结期（文臣定策、武将备战、全国动员）→ 有限时间窗的攻城节点推进会战 → 战后双账结算与恩怨写入；非战时以边境摩擦与暗战维持张力。

**在整体中的位置**：
- 它是支柱二"国运涌现"的**最强表现场**：版图改变、灭国/复国、史书史诗都从这里产生。
- 它是文武官职体系的**终极协作场**：文臣持节杖定战局之策（外交施压/情报判读/临阵斡旋），武将持兵符执攻略之役（节点统领/先锋/守御）——"文臣定策、武将执行"在战时达到最高戏剧浓度。
- 它**不拥有**宣战决定权（AI 君主独占，S1 事件决策出口）、**不定义**国力数值（战果作为收益申报事件交 S2 结算）、**不管理**战时任务实例（复用任务系统，本系统产出战时任务潮需求）。
- 会战制（相对全天候乱斗）的策划本质：**把战争做成"有幕间的大戏"**——集结期是政治戏（合纵连横、外交绞杀），会战窗口是动作戏（节点攻防），幕间（非战时）是暗战戏（摩擦/间谍/经济战）。

```
[宣战决策] S1 AI 君主（独占终决）→ 事件诏令
     ↓
W1 外交前置 → W2 集结期 → W3 会战窗口（攻城节点推进） → W6 战后结算
     ↑            ↑              ↑                        ↓
   外交系统      S2 国力消耗      任务系统(战时任务潮)      S2 双账 + S1 恩怨账本 + 史书
```

## 2. 设计目标与反目标

### 目标

| # | 目标 | 验证方式 |
|---|---|---|
| G1 | **平民战时意义感红线**（GDD-0 风险 4）：非战斗玩家的战时贡献（后勤/间谍/动员/造械）占比可感知、计军功 | 平民战时贡献占比 ≥ 30%；战时留存无异常下滑 |
| G2 | **文武战时互需**：文臣策略（方略/斡旋）实际影响战局走向，武将执行决定节点归属 | 斡旋成功改写战局的会战占比、军策功结算量 |
| G3 | **节奏仪式感**：宣战-集结-开战-结算四幕节拍清晰，会战是"全服事件"而非日常 | 会战窗口在线峰值增幅、集结期动员参与率 |
| G4 | **AI 战争人格一致**：宣战/停战/战时诏令符合君主人格与恩怨账本（燕隐忍不轻战、楚好豪言易被激） | S1 人格回归测试含战时场景 |
| G5 | **小国生存玩法成立**：弱国凭文臣外交/间谍方略可求存（GDD-0 小国保障） | 弱国非战手段化解宣战的案例率 |

### 反目标（本系统明确不做的事）

| # | 反目标 | 理由 |
|---|---|---|
| A1 | **不做全天候自由国战**：无宣战无会战，边境摩擦有频控 | 会战制是用户定稿 ✔；乱斗稀释会战仪式感、放大数值碾压 |
| A2 | **玩家不拥有宣战权**：宣战/停战终决权 AI 君主独占（GDD-0 4.3），玩家只能推动（上书主战/主和、外交施压） | 支柱一：战争是"君主的意志"，这是 AI 君主戏剧性的最大舞台 |
| A3 | **不设个人战力碾压通道**：会战结算以节点集体推进为准，个人军功是贡献计量不是胜负开关 | 平民意义感红线；战力通胀防不了但可不让它决定国运 |
| A4 | **不做战时跳过/速通**：集结期不可跳过（外交机会必须真实存在） | 集结期是文臣线的核心舞台，砍它等于砍战时文臣玩法 |
| A5 | **不直接改写国力**：战果走 S2 收益申报（声明-结算-归因链全流程） | 对齐 S2 反目标 A1/A2，国力变化必须可追溯 |

## 3. 系统拆解（8 子模块）

| 模块 | 职责 | 输入 | 输出 |
|---|---|---|---|
| W1 宣战与外交前置 | 承接 S1 宣战事件诏令；开战理由叙事包装；外交前置窗口 | S1 事件决策、外交系统状态 | 会战实例创建、开战檄文 |
| W2 集结期（2-3 天） | 全国动员阶段：筹粮/造械/募兵/间谍/外交施压并行 | S2 国力（粮/械消耗）、任务系统 | 集结度、双方战备值、斡旋窗口 |
| W3 会战窗口与攻城节点推进 | 有限时间窗（默认 48h）内的节点攻防推进 | 集结期产出、兵符持有者 | 节点归属变化、战局进度 |
| W4 兵符/节杖系统 | 战时权限载体：兵符=军事指挥权限，节杖=外交/战术权限 | 官职系统（席位）、战功 | 高阶战时任务领取资格、战术卡/斡旋卡发放 |
| W5 战时角色体系 | 非战斗玩家的战时角色与军功通道（G1 红线） | 战时任务潮 | 后勤/间谍/动员/造械军功记录 |
| W6 战后结算与恩怨写入 | 节点结算→战果申报 S2→军功/军策功双账→恩怨账本（灭国之仇=硬记忆） | W3 结果 | 国力变化申报、双账流水、S1 入账事件 |
| W7 复国线 | 灭国后流亡士人玩法：复国资源收集/旧臣联络/复国宣战 | 灭国结算 | 复国进度、复国宣战事件（交 S1） |
| W8 暗战与边境摩擦 | 非战时张力维持：摩擦事件、劫掠、经济战、间谍战 | 外交系统事件流 | 摩擦计数（进 S1 M2 快照）、低烈度军功 |

### 3.1 W1 宣战与外交前置

- **宣战流程**：玩家/摄政主战推动（上书/廷议）→ AI 君主按人格+恩怨账本+国力裁定（S1 事件决策）→ 事件诏令即**开战檄文**（人格化叙事："韩使三日不至，寡人先发"式）。AI 也可自主宣战（恩怨账本怨值累积、历史引力命题推进）。
- **外交前置窗口**：檄文发布后至集结期结束前，目标国的文臣可发起斡旋（节杖权限）；斡旋成功条件见 §4.2——AI 君主依人格给斡旋设定"台阶"（秦容错低难斡旋、韩忧患型给台阶但要重礼）。
- 会战实例一经创建不因君主更替/摄政更替而取消（旬快照语义）。

### 3.2 W2 集结期

- 双方全国任务潮切换为**战时任务潮**（W5 模板 + S1 主推权衡），产出四类战备值：粮秣、军械、士气、情报。
- **外交绞杀**：第三方国可对交战双方施压/许诺/威胁（外交系统），文臣主战场。
- **间谍战**：渗透任务降低对方战备值/泄露节点布防（情报值影响 W3 开局可见度）。
- 集结度不足可导致 AI 君主**推迟开战**（人格化诏令："粮秣未集，师出无名"）——AI 保留节奏权，对齐 A5。

### 3.3 W3 会战窗口与攻城节点推进制

- 窗口默认 48h（集结 2-3 天 + 会战 2 天 ≈ GDD-0"2-3 天集结"总节拍，▲最终由节奏测试定）。
- 节点按有向推进图组织（见 §4.2）：攻方须按序攻克，守方夺回可逆转——**战线是拉锯的**，不是倒计时血条。
- 每节点攻防以"推进度"结算：完成战时任务（前锋突击/守城/断粮/造械）贡献推进度，个人战斗行为（PVP）贡献局部小规模遭遇战胜负——**任务贡献为主、PVP 为辅**（A3）。
- 窗口结束按节点归属结算；未被攻克的首都节点=守方存续。

### 3.4 W4 兵符/节杖系统

- **兵符**（武将路战时权限）：持符者可领"统领类"高阶战时任务（督战/节点总攻/伏兵），符随席位（上将军/司马/尉）与战功临时授予；MVP 简化。
- **节杖**（文臣路战时权限）：① 斡旋卡（外交前置/会战窗口内劝退、召唤援军）；② **战术卡**（一次性临阵献策：夜袭/坚壁/示弱诱敌——由 AI 君主或战时摄政裁定是否采用，采用则修正节点推进规则或 morale，采纳记录入军策功归因链）。
- 符/杖均**不可转让、不可交易**（A3 延伸：战时权限不走经济系统）。
- **（REV-006 注记）客卿边界**：兵符统领类动作**永不接受全自动客卿操作**（强制人工确认，GDD-S7 §6.3）；会战窗口内 L3 客卿会战动作限频减半（6 次/日）——指挥责任不可让渡，与"摄政不可让渡"同构。**（v0.5 注记，口径更新）**随玩家主权原则与 S7 v0.4 修订：兵符军令**可代行但实时署名**；玩家手动军令**即时抢断覆盖**其客卿未结算的代行军令（节点推进度结算批次前可撤销），主权原则在会战域的落点。**（v0.6 注记）离线约束**：会战窗口（ASSEMBLY 末段+BATTLE_WINDOW）内兵符军令**不可离线代行**（守舍之约不覆盖）——会战要求玩家在线，防"挂机打赢会战"稀释全服事件仪式感（S7 §3.6 定稿）。

### 3.5 W5 战时角色体系（G1 红线落地）

| 角色 | 职能 | 军功计量 |
|---|---|---|
| 后粮官 | 筹粮/护送辎重 | 按送达量折军功 |
| 军械匠 | 造械/修械 | 按器械入列数 |
| 动员吏 | 发布动员、招募 NPC 兵源 | 按动员完成度 |
| 谍报士 | 渗透/反谍/情报判读 | 按情报值贡献 |
| （战斗类）先锋/守卒 | 遭遇战 PVP、据点小规模战 | 按战果（辅） |

- 战时任务潮按 W5 角色类型配比下发（民生类任务平时照常，但优先级让位战时潮——S1 M5 占比上限在战时对"军需类"豁免放宽至 60% ▲待 S1 联动确认）。

### 3.6 W6 战后结算与恩怨写入

- 结算顺序：节点归属 → 领土/资源变化申报 S2（`war_result_events`，含声明收益）→ 军功/军策功双账结算 → 战报诏令（AI 君主人格化复盘）→ 恩怨入账。
- **恩怨规则**：灭国之仇 = **硬记忆**（跨季全量，S1 M8）；战场点名羞辱、阵前倒戈 = GRUDGE/BETRAYAL；斡旋有功 = FEAT。战败方君主语录倾向由人格决定（韩忧患自责、楚浪漫扬言复仇——复仇叙事进下一季引力）。

### 3.7 W7 复国线

- 灭国后：国民转"流亡士人"，保留原国身份牌；复国资源收集（流亡任务潮）、旧臣联络（社交玩法）、复国宣战（达标后交 S1 事件决策——AI 君主对旧国复国的态度按恩怨账本：旧臣忠诚=FEAT 加成）。
- 复国成功 = 史书"复国史诗"最高素材（支柱二）。

### 3.8 W8 暗战与边境摩擦

- 非战时默认态：摩擦事件（外交系统推送 S1）、劫掠 PVP（限频、有赏格）、经济暗战（商路干扰）、间谍网经营。
- 摩擦计数连续超阈值 → 成为 S1 自主宣战的决策依据之一——暗战是玩家"推动 AI 开战"的杠杆。

## 4. 数据规格

### 4.1 会战阶段状态机

```
PEACETIME ──宣战事件诏令──→ DECLARED ──→ ASSEMBLY(2-3d) ──集结度达标──→ BATTLE_WINDOW(48h) ──窗口结束──→ SETTLED ──→ PEACETIME
                              │               │                        │
                              │               └──斡旋成功/君主延期──→ CANCELLED / DEFERRED(+1旬,≤2次)
                              └──（外交前置窗口内）斡旋成功 ──→ CANCELLED
```

- 状态迁移事件全部入事件溯源总线（对齐架构）；`SETTLED` 后生成会战档案（透明日志可查）。
- DEFERRED 上限 2 次：第 3 次集结不足 → AI 依人格"罢兵"（CANCELLED + 怨值入账"师出无功"）。

### 4.5 军功/军策功结算规则（与 S2 归因链对齐）

- **军功**（执行侧）：走 S2 事功链——战时任务的 `delta_events.executor` 正常入账，另加 `war_merit` 字段（会战作用域内汇总，交官职系统）。**（v0.4 注记）决策与执行等价：军功/事功为武路成长主轴，与文路策功权重等价（S5 §4.2 v0.4 表）——战功不是政治玩法的附属品。**
- **军策功**（定策侧）：走 S2 策功链扩展——斡旋卡/战术卡/判读方略生成 `strategy_event`：
  - 斡旋成功 → 战果申报中"避免的国力损失"折算为正增量计入提案人军策功（反事实量化由外交系统申报 ▲）；
  - 战术卡采纳 → 该节点后续推进度变化的归因份额（默认 20%）计入献策人 ▲比例待数值标定；
  - **归因分摊完全沿用 S2 §4.5 口径**：只算直接增量，AI 裁定与自然因素不入军策功。
- **策罪战时版**：献策采纳后节点反陷 → 军策功转负 + 君主问责语录（对称设计，文臣战时同样担责）。

## 5. 玩家交互流程（四阶段 × 四层）

| 阶段 | L1 布衣 | L2/L3 文臣 | 武将 | L4 摄政 |
|---|---|---|---|---|
| **宣战** | 看檄文（朝堂烛火演出）；接动员任务 | 上书主战/主和（AI 裁定参考）；外交前置斡旋 | 预征召通知 | 战时动员令节奏权限启动 |
| **集结期** | 后勤/造械/动员任务（军功线开启） | 筹粮方略、间谍网部署、第三方外交绞杀 | 募兵督练、先锋编成、领兵符 | 俸禄/封赏向军功倾斜的分配权 |
| **会战窗口** | 战地任务（运粮/修械/小规模遭遇战） | 持节杖：临阵战术卡、劝退/召唤援军 | 持兵符：节点统领、突击/守御 PVP | 廷议可议战事，宣战停战无权（AI 独占） |
| **战后结算** | 军功入账、战报诏令 | 军策功/策罪公示（归因时间线可分享） | 军功晋爵、战场点名（或被点名） | 政绩记入摄政考评 |

- **非战斗玩家的战时体验承诺**（G1）：战时任务潮中非战斗类占比 ≥ 50%；军功计量与战斗军功同表同权（同一晋爵曲线）——"运粮的也配记功"是硬规则不是口号。
- **关键体验时刻**：开战檄文的宣战大殿演出（视觉锚点④）；节点易手的战报即时推送（水墨战线晕染变化，视觉锚点③）；战后君主人格化复盘语录。

### 7.1 MVP 实现范围

| 模块 | MVP 实现 | 砍掉/简化 | 恢复时机 |
|---|---|---|---|
| W1 宣战前置 | **剧本化触发**：MVP 中段固定事件（楚·汉水摩擦累积 → 秦 AI 君主自主宣战），非玩家可推动 | 玩家主战推动链 | V1 |
| W2 集结期 | 实装 2 天：粮秣/军械/士气三类战备值 | 间谍战、第三方外交绞杀 | V1 |
| W3 会战窗口 | 实装 36h、**3 节点**（汉水渡口→郢都北门→郢都内城）线性推进图 | 拉锯夺回、复杂 DAG | V1 |
| W4 兵符/节杖 | **兵符实装**（统领任务资格）；节杖砍战术卡，仅保留 1 类斡旋卡（劝退） | 战术卡、召唤援军 | V1 |
| W5 战时角色 | 实装 4 角色中 3 类：后粮官/军械匠/动员吏（谍报士砍） | 谍报士 | V1 |
| W6 结算 | 实装：战果申报 S2、军功双账、灭国结算（楚可灭→触发复国线占位提示） | 战场点名演出、复仇引力叙事 | V1 |
| W7 复国线 | **整体砍掉**（灭国后流亡士人只保留身份牌与提示） | 全部 | V1（GDD-0 承诺，不缺席正式版） |
| W8 暗战 | 摩擦事件由剧本供给（驱动宣战） | 劫掠/经济战/间谍网 | V1 |

### 7.2 MVP 砍留原则

留：集结期+节点推进+平民军功线+兵符——这四项分别验证"节奏仪式感/会战玩法成立/G1 红线/文武战时互需（武将侧）"。
砍：复国线与暗战——重要但非"一场会战"验证所必需；斡旋卡保留 1 类使文臣战时价值有最小验证口（军策功链路打通）。

## 8. 验证指标

### 8.1 核心指标

| 指标 | 定义 | 目标值 | 采集 |
|---|---|---|---|
| **会战参战率** | 会战窗口内完成 ≥1 次战时任务的活跃玩家占比 | ≥ 50% | 结算日志 |
| **平民战时贡献占比**（G1 红线） | 非战斗类战时任务贡献 / 总战时贡献 | ≥ 30% | 结算日志 |
| **战时任务潮非战斗占比** | 下发任务中后勤/造械/动员类占比 | ≥ 50% | 任务系统 |
| **集结期动员率** | 集结期完成 ≥1 次动员任务的活跃玩家占比 | ≥ 40% | 结算日志 |
| **军策功有效率** | 斡旋卡/方略被 AI 采纳且产生可归因效果的比例 | 20%-50% 带宽（过低=文臣战时无用感；过高=AI 无主见） | S2 策功链 |
| **会战节奏感知** | "会战像全服大事件而非日常乱斗"问卷（5 分制） | ≥ 4.0 | 赛后问卷 |
| **在线峰值增幅** | 会战窗口 DAU 峰值 / 旬均 DAU | ≥ 1.2 | 数据后台 |
| **弱国生存玩法使用率** | 弱国被宣战时斡旋/外交手段启用率 | ≥ 60%（G5） | 外交系统 |

### 8.2 护栏指标

| 指标 | 阈值 | 说明 |
|---|---|---|
| 战时留存异常 | 会战期间战败国 7 日留存环比降幅 ≤ 15% | 超限触发复国线提前评估 |
| PVP/任务贡献比 | 遭遇战贡献占节点推进 ≤ 25% | A3：任务为主 PVP 为辅的硬约束 |
| 宣战频次 | 单国每赛季主动宣战 ≤ 3 次（AI 人格外） | 防战争疲劳；超限为 AI 调参事故 |
| 会战准时结算率 | 100%（窗口结束必须出结果，含"惨胜/守住"） | 节奏承诺 |
