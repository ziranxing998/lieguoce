## 1. 系统概述

**一句话**：灭国后世界状态管理系统负责"一个国家死亡之后世界如何继续运转"——它接管灭国判定后的权力移交、领土资源再分配、流亡士人状态托管与复国进程，并施加均势补偿防止征服国滚雪球，把灭国从"内容蒸发"转化为本作最强的叙事阶段（复国史诗/流亡政治/征服者叙事）。

**在整体中的位置**：
- 它是支柱二"国运涌现"的**止损与转译器**：没有它，灭国=玩家资产清零+服务器平衡崩坏；有它，灭国=流亡政治玩法开启+征服者背负"灭国之仇"硬记忆+史书史诗素材。
- 它**上游承接** S3 的灭国结算（谁灭的、何时、何因），**下游服务** S1 恩怨账本（硬记忆条目）、S2 赛季快照（FALLEN 国的国力曲线封存）、史书系统（复国/灭国史诗）。
- **它不判定灭国**（灭国判定条件属 S3 W3/W6：首都节点陷落即灭国，本系统在 `SETTLED` 后接管）、**不经营复国玩法细节任务**（复国资源任务复用任务系统）、**不裁决外交**（流亡政府的外交行为走外交系统，身份特殊化处理）。

```
[S3 W6 灭国结算] ──灭国事件──→ 【GDD-S4 世界状态管理】
                                    ├─→ S1 M8：灭国之仇（硬记忆）+ 通缉/流亡身份
                                    ├─→ S2：FALLEN 国国力封存 + 征服国收益结算
                                    ├─→ 任务系统：流亡任务潮 / 征服国安抚任务潮
                                    ├─→ 外交系统：流亡政府特殊外交身份
                                    └─→ 史书系统：灭国史诗 / 复国史诗素材
```

## 2. 设计目标与反目标

### 目标

| # | 目标 | 验证方式 |
|---|---|---|
| G1 | **流亡玩家留存**：灭国后流亡士人 7 日留存 ≥ 全服均值 80%，且保留完整回归路径 | 流亡分群留存监控 |
| G2 | **复国是真实可及的目标**：复国条件透明、进度可见、成功率在合理区间（非必然也非绝望） | 复国进度面板渗透率、复国成功率区间监控 |
| G3 | **防滚雪球**：征服国不能无代价吞并扩张，世界均势在 2-3 旬内重建 | 征服国国力增速监控、旁观国制衡行为率 |
| G4 | **灭国叙事最大化**：灭国/复国全程产出可讲述的史诗素材（恩怨、语录、列传） | 灭国事件语录截图率、史书素材完整度 |
| G5 | **恩怨硬记忆兑现**：灭国之仇按 S1 硬记忆规则跨季保留并持续影响决策 | S1 回归测试含灭国场景 |

### 反目标（本系统明确不做的事）

| # | 反目标 | 理由 |
|---|---|---|
| A1 | **不复活即删号**：灭国玩家绝不回退为"白板"，身份牌/官职履历/恩怨全保留 | 支柱三与玩家资产承诺（GDD-0 复国线定稿） |
| A2 | **不放任世界失衡**：灭国后不做"弱肉强食自由放任"，均势补偿是明规则 | 滚雪球会让赛季中段结局失去悬念，"国运涌现"需要多结局可能 |
| A3 | **不做即时复国**：灭国当旬不可立即复国（最短流亡期 2 旬），复国是经营目标不是续命道具 | 即时复国让灭国惩罚归零，征服玩法失去意义 |
| A4 | **不强制流亡者复仇**：流亡者可自由选择复国、择木而栖改换门庭或超然独处 | 玩家自由是支柱三前提；强制复仇制造绑架式社交 |
| A5 | **不搞隐藏复活彩蛋**：复国条件全透明公示，不藏 GM 后门 | 对齐"透明可复盘"全作原则 |

| X5 复国战争触发与结局 | 复国宣战条件判定、复国战争实例（复用 S3 会战）、复国成功/失败结局 | X4 进度、S1 事件决策 | 复国事件、RESTORED/消亡终局 |

| X8 赛季结算兼容 | FALLEN 国在赛季结局评定中的口径、流亡者跨季遗产 | S2 赛季快照 | 结算修正项 |

### 3.1 X1 灭国判定与权力移交

- 判定来源：S3 W6 结算——守方**全部 INNER 节点陷落**即灭国（单节点丢失不灭国，保"守住"叙事）。
- 权力移交内容：领土控制权、NPC 官员体系（转为征服国治理任务对象）、原国朝堂席位（清空、原持有者转流亡）、原国 AI 君主**退位但人格不灭**——沦为"亡国之君"状态（若复国则复位，其语录与恩怨连续——"寡人必雪此恨"）。
- 亡国之君的 AI 决策：FALLEN 期不再发布国策诏，但保留**流亡宫廷事件**（低频：遗诏、密信、复国檄文——人格化叙事的火种，成本低：每旬 ≤1 条模板化+批处理）。

### 3.2 X2 领土与资源再分配

- 领土划转即时生效（水墨地图晕染变化）；征服国获得城邑产出（S2 声明收益），但需**治理投入**（安抚任务潮：安民/驻防/任用降臣）——无治理则占领区产出衰减+叛乱事件流：**占领是有成本的**（G3 防滚雪球第一杠杆）。
- FALLEN 国五维数值**封存不归零**（复国时以折减值恢复，见 §4.3）。

### 3.3 X3 流亡士人状态

- **保留**：身份牌（原国贵族纹章灰化）、官职履历与散阶（冻结不清零）、个人声望、与原国君主的恩怨（硬记忆）、家族谱系、技能熟练度。
- **冻结**：原国官职席位权限（席位回归国家席位池）、俸禄。
- **新增**：流亡士人身份特权——可投奔任意国（**豁免择木而栖的声望损耗**，流亡已是最大折损；但 30 天冷却与履历按国隔离规则照常）、复国玩法入口、流亡社群（旧臣联络）。

### 3.4 X4 复国资源线

三类复国资源（复国进度 = 三资源加权）：**复国资金**（流亡任务/旧贵族捐输）、**旧臣联络**（拉回流亡同僚与故土人心）、**义兵募众**（故土民心动员——依赖征服国治理质量：治理越差，义兵越易募，对齐 G3 第二杠杆）。

### 3.5 X5 复国战争触发与结局

- **触发条件（全透明公示）**：① 流亡期 ≥ 2 旬；② 三资源达标（建议阈值：资金 60 / 联络值 40 / 义兵 50，▲数值标定）；③ 发起人须为原国大夫档以上流亡者（对齐摄政门槛逻辑——复国也需要"有履历的旗手"）；④ 向 S1 提交复国宣战 → AI 君主裁定（原国君主人格+恩怨账本：征服国之仇必应——复国宣战几乎必准，但可因国际形势被劝阻）。
- 复国战争 = S3 会战实例（复用节点推进制，复国方为攻方、目标 3 节点：夺回故都）。
- **结局**：成功 → RESTORED（国力按折减值恢复、君主复位、史诗写入、征服国蒙受"失土之耻"怨账）；失败 → 终局分支：流亡状态延续（资源折半保留，"卷土重来"）或赛季末 ANNEXED（并入征服国版图，流亡者转纯个人流亡，身份牌入史馆）。**不设第三次复国机会限制，但资源折半的代价递增**（两次失败后阈值 ×1.5）。

### 3.6 X6 均势补偿机制（明规则，A2/A1 对齐）

| 杠杆 | 机制 | 申报口径 |
|---|---|---|
| 治理成本 | 占领区产出 30% 起步被治理消耗吸收，治理任务不足则衰减 | source=OCCUPATION_COST，明示 |
| 合纵引力 | 灭国事件提升其他五国对征服国的戒备值（外交系统）：会盟/互保条约意愿上升、对征服国的间谍容忍度提高 | 交外交系统，不改国力 |
| 降臣任用 | 征服国任用原国大夫档以上降臣可提升治理效率，但该降臣在原国恩怨账本记 GRUDGE（"仕仇"）——用旧臣要付恩怨代价 | S1 入账 |
| 义兵杠杆 | 见 X4：征服国治理越差，复国越易 | 已含 |

- **设计红线**：均势补偿**全部是间接杠杆**（成本/外交/人心），无一费是"系统直接扣征服国国力"——对齐 S2 反目标 A1（不做暗平衡器），补偿可被玩家理解、可被征服国对策化解（好好治理就没事）。

### 3.7 X7 历史叙事写入

灭国檄文/亡国之君遗诏/复国檄文/复国史诗四类叙事事件模板（人格卡参数化）→ S1 M7 语录生成管线（双审）→ 史书素材包。恩怨写入：灭国之仇（征服国↔原国，HARD/NEVER）、"仕仇"降臣（软）、复国恩人（FEAT）。

### 3.8 X8 赛季结算兼容

- FALLEN 国赛季评定：以灭国时点国力曲线参与结局评定（"存续"项记 FALLEN），流亡者个人按流亡期表现计跨季遗产（官职履历冻结值 × 流亡活跃系数）。
- 复国成功在结算中记 RESTORED，"复国史诗"作为史书独立章节。

## 4. 数据规格

### 4.1 国家状态机

```
ACTIVE ──S3 灭国结算──→ FALLEN ──复国战争成功──→ RESTORED（=ACTIVE，带史痕）
                          │
                          └──赛季末未复国──→ ANNEXED（版图并入，原国叙事封存入史馆）
                                              │
                                              └──赛季结算（S14 H2）──→ 新季 ACTIVE（带"故地"史痕）
```

- **ANNEXED 跨季重入路径（REV-WRITEBACK 修订：跨文档一致性，结 S14 Q2 玩家侧）**：ANNEXED 为**季内终局态**，不直接迁移——赛季结算（S14 §3.2 H2）后该国在新季状态机以 **ACTIVE 重入**，附"故地"史痕标记与复国线钩子参数预置（S14 §3.5 H5 史痕开局）；流亡者（ANNEXED_PERSON）新季开局 = 可择任意国复籍（豁免声望损耗）或随征服国入籍，**原国复国资格保留一季**（一季内可对故土发起复国宣战，逾期转纯个人流亡、身份牌史痕入史馆）。

| 字段 | 类型 | 示例值 | 说明 |
|---|---|---|---|
| `state_id` / `nation` | string | `"fallen_han_s2"` | |

### 4.3 复国进度指标

`restoration_progress = 0.4×funds + 0.3×liaison + 0.3×militia`（权重：资金为先——义兵无粮不聚 ▲标定）
触发线：progress ≥ 60（首战）；每次失败后阈值 ×1.5。进度全服公示（透明+招募传播）。

### 4.4 均势补偿参数建议值

| 参数 | 建议值 | 依据 |
|---|---|---|
| 占领区治理吸收率 | 30%（治理任务充分）/ 60%（不足时衰减） | "占而不管 = 白占"：30% 起步让征服有利可图但不暴利，60% 惩罚线驱动安抚任务潮 |
| 治理不足衰减速率 | 占领区产出 -5%/旬 | 2-3 旬内可感知，倒逼征服国投入 |
| 复国资源折减（复国成功时国力恢复） | restoration_discount = 0.8 | 复国是"艰难中兴"不是"原地满血" |
| 义兵增益上限 | +30% 义兵募众速度（治理最差时） | 惩罚上限封顶，防"摆烂钓复国"的恶意策略 |
| 降臣治理效率加成 | +15%/名（上限 2 名） | 让"仕仇"的恩怨代价有对价 |

## 5. 玩家交互流程（三视角）

| 视角 | 关键路径 | UI/体验要点 |
|---|---|---|
| **流亡者** | 灭国演出（王城陷落/君主最后诏令）→ 保留身份牌灰化动画 → 流亡抉择（投他国/留流亡营/筹复国）→ 复国进度面板（三资源+全服公示）→ 复国檄文（发起权）→ 复国战争 | **灭国不是失败结算画面，是叙事开场动画**；身份牌灰化但"触碰可见旧纹章"（复国钩子）；复国进度条以"义旗渐张"先秦语感呈现 |
| **征服国玩家** | 占领区治理任务潮（安民/驻防/任用降臣抉择）→ 治理质量 ↔ 义兵风险此消彼长 → 灭国之仇硬记忆的社会压力（他国戒备、间谍增多） | 治理是"打下来之后真正的玩法"；任用降臣时明示恩怨代价（"此人旧主之臣，用之需防其心"） |
| **旁观国玩家** | 灭国新闻诏令（七国同知）→ 合纵引力变化（对征服国戒备可视化）→ 灭国流亡士的招募窗口（本国获流亡人才，豁免损耗） | 旁观者的"合纵窗口"是暗线玩法：借灭国之势重组外交格局（对齐 G3 明规则杠杆） |

| 官职系统 S5 | 席位清空/冻结、大夫档门槛校验 | X1/X5 | 强依赖 |

### 6.2 下游服务

| 系统 | 数据 |
|---|---|
| 史书系统 | 灭国/复国史诗素材包、ANNEXED 封存档案 |
| 任务系统 | 流亡任务潮 / 征服国安抚任务潮 |
| 家族系统 | 家族谱系跨灭国保留（流亡不散族） |

### 6.3 不做越界

- 不判定灭国（S3 职责）、不裁定复国宣战（S1 职责，本系统只校验触发条件后提交）。
- 不给流亡者发"补偿性国力"（个人资产保留，国家数值只走 X2 规则）。
