# GDD-S5 · 官职与声望 系统 GDD

> 文策渊 · SYS-S5 · 系统设计阶段产物
> 上游依据：`GDD-0 v0.2` §五（散阶八档+稀缺席位、重转换、履历资产）、§4.3（摄政大夫档门槛、三重指标）、`GDD-S2`（策功/事功归因账本，§4.4 策功分换算遗留项在此标定）、`GDD-S3`（军功/军策功）、`GDD-S4`（席位冻结/流亡豁免）

## 1. 系统概述

**一句话**：官职与声望系统是玩家政治生涯的"资产负债表"——它把 S2/S3 产出的策功/事功/军功/军策功归因流水按路别加权换算为**声望**，以声望+履历驱动**散阶八档**的晋升降级，管理**稀缺席位**的任命/免职/任期，并运行**推举票**机制，最终为摄政资格（大夫档门槛+三重指标）与跨季遗产提供唯一权威数据。

**在整体中的位置**：
- 它是支柱三"君臣共治"的**计分与发牌系统**：S2/S3 负责"产生功过"，本系统负责"记账、定阶、授位、开票"。
- 它**不产生**功过数据（S2/S3 职责）、**不决定** AI 决策内容（席位只影响 S1 权重面）、**不运行**廷议与弹劾流程（摄政系统职责，本系统供数据）。

```
[S2 策功/事功账本] ─┐
[S3 军功/军策功]  ─┼─→ 【GDD-S5 官职与声望】 ─→ S1（席位→决策权重面）
[玩家行为流水]    ─┘         │                  摄政系统（三重指标/资格门槛）
                        声望 → 散阶 → 席位 → 推举票 → 跨季遗产（赛季系统）
```

## 2. 设计目标与反目标

### 目标

| # | 目标 | 验证方式 |
|---|---|---|
| G1 | **差异化靠官位稀缺而非技能门槛**（GDD-0 v0.2 定稿）：席位名额 + 档位门槛构成真实竞争 | 席位竞争率（候选/席位比 ≥ 2:1） |
| G2 | **功过对称可预期**：策功/事功/策罪的声望后果玩家可在事前理解、事后追溯 | 声望流水可追溯率 100%；晋升预期问卷 ≥ 3.8 |
| G3 | **文武双轨等价性**：两路的声望获取速率与晋升曲线在经济上等价（等投入等回报） | 双路声望获取速率差异 ≤ 10%/旬 |
| G4 | **防刷票防挂机**：推举票、席位贡献、档位维持全部有活跃度锚 | 异常票作废率监控、挂机席位自动清退率 |
| G5 | **跨季遗产成立**：本季履历可感知地兑换下季起点 | 遗产领取率、遗产玩家次季留存对比 |

### 反目标（本系统明确不做的事）

| # | 反目标 | 理由 |
|---|---|---|
| A1 | **不用声望直接购买 gameplay 数值**（攻击力/资源产量） | 声望只兑换政治权限（席位/对话配额/推举资格），防"元老院碾压新人"的数值世袭 |
| A2 | **不做 AI 自动任免一切**：席位任命必须经 AI 君主裁定+玩家推举双通道，缺一不可 | 纯 AI 任命=玩家无法建立政治派系；纯玩家推举=人气刷子接管朝堂 |
| A3 | **不做档位永久保底**：散阶可降（挂机/功过），防"躺赢元老" | 档位流动是 G4 的前提 |
| A4 | **不做声望交易/转移** | 对齐 S2 反目标 A3；政治资本不可代购 |
| A5 | **不隐藏换算规则**：全部权重与门槛公示（游戏内"官制典章"页） | 对齐 S2 A2 可追溯原则 |

## 3. 系统拆解（7 子模块）

| 模块 | 职责 | 输入 | 输出 |
|---|---|---|---|
| P1 声望账本 | 声望流水记账：获取/折损全事件，来源可追溯 | S2/S3 记分、折损事件 | 声望净值 + 全量流水 |
| P2 换算引擎 | 归因记分 → 声望点的路别加权换算（公式见 §4.2） | S2 strategy_score / deed_score、S3 war_merit | 声望增量事件 |
| P3 散阶阶梯 | 八档晋升/降级判定（门槛+功过抵扣） | 声望净值、任官履历 | 档位变更事件 |
| P4 席位管理 | 席位池、任命/免职/任期、空缺选举触发 | AI 裁定、推举结果、贡献监控 | 席位状态（→ S1 权重面） |
| P5 推举票系统 | 投票资格、计票、防刷、选举事件 | 廷议事件、玩家投票 | 选举结果（→ P4） |
| P6 履历与跨季遗产 | 履历档案（文/武/双修路径）、赛季末遗产折算 | P1-P5 全量数据 | 遗产包（→ 赛季系统）、名臣列传素材 |
| P7 防刷与风控联动 | 活跃度锚、同簇识别、异常审计 | 风控系统 | 作废/降权裁定 |

### 3.1 P2 换算引擎（核心，标定 S2 遗留）

见 §4.2 公式与权重表——这是全系统数值中枢：S2/S3 只出**归因记分**（无量纲），本模块是唯一换算为声望的出口（单一出口防双头口径）。

### 3.2 P3 散阶阶梯

八档：下士→中士→上士→下大夫→中大夫→上大夫→下卿→上卿。晋升 = 声望门槛 + 履历门槛**双条件**（§4.3）；功过抵扣规则与降级条件见 §4.4。

### 3.3 P4 席位管理

- 席位类型与权限面（对齐 S1 §5：席位=影响 M2/AI 决策权重面）：文席位 相邦（总揽，摄政强关联）/司徒（民生经济议题）/太史（文化+历史引力话题可见度）/行人（外交议题）；武席位 上将军（战时统领，兵符源）/司马（军政军法议程）/尉（都尉，防务议程）。
- **任期 = 一季**；任命时点 = 旬初朝会（快照语义对齐 REV-003：旬内换官按快照时点在任者生效）；任期中空缺（免职/流亡/灭国）触发补选（P5）。
- 免职三通道：① AI 君主裁定（恩怨/问责/国力连亏连带——入恩怨账本）；② 弹劾连带（摄政系统弹劾流程产出，本系统执行）；③ **挂机自动请辞**：连续 2 旬席位贡献为零 → 自动卸任+诏令公示（"卿久旷职守，印绶收回"）。

### 3.4 P5 推举票

见 §4.5。选举事件两类：席位空缺补选、季末摄政推举（三重指标中的"朝堂推举票"由此产出）。

### 3.5 P6 履历与跨季遗产

- 履历档案 = 文/武/双修路径 + 任官序列 + 功过大事记（S2/S3 归因链引用），是名臣列传与 AI 君主态度偏好（人格卡 player_affinity）的数据源。
- 跨季遗产（GDD-0 八节"声望遗产影响下季初始官职"）：见 §4.6。

## 4. 数据规格

### 4.1 声望流水字段

| 字段 | 类型 | 示例值 | 说明 |
|---|---|---|---|
| `entry_id` / `player_id` | string | | |
| `source_type` | enum | `"STRATEGY_MERIT"` | STRATEGY_MERIT(策功) / DEED(事功) / WAR_MERIT(军功) / WAR_STRATEGY(军策功) / TASK(日常任务) / PENALTY(折损) / EQUILIBRIUM(遗产) |
| `ref_id` | string | `"prop_han_x13_007"` | 回指 S2/S3 归因链 ID（可追溯，G2） |
| `raw_score` / `weight` / `prestige_delta` | float | `42 / 1.0 / 42` | 原始记分 / 路别权重 / 换算后声望增量（REV-WRITEBACK 修订：跨文档一致性——示例权重对齐 §4.2 v0.4 权重表文路策功 w=1.0；原示例 1.3 为军策功旧值） |
| `track` | enum | `"WEN"` | WEN(文) / WU(武) / BOTH(双修共有) |

- **（REV-006 注记）`source_type` 增设 `AGENT_ASSIST`**：客卿代拟/代理（GDD-S7）产生的功过**归因玩家本人、数值零差别**，仅以该标记供审计分群与公平性带宽监控（S7 §8.1）；托管等级门槛复用散阶档位（上士/大夫/上大夫）。
- **（v0.5 注记）玩家主权原则**：客卿代行（投票/提案）与手动操作**同权计票、同权计分**——原则不削弱代行效力，只保证未结算前可覆盖可撤销（如开票前可改票）；摄政考评政绩聚合同理。**（v0.6 注记）代票标记**：守舍之约期间的离线代票同权计票，但公开标注"代票"（delegate_vote）——同权不等于匿名，知情权是全国的。
- **（v0.7 注记）席位与离席联动**：席位持有者失期（GDD-S9）第 3 旬由 AI 暂收席位+补选，原主回归享复任优先权（空缺且仍具资格时免推举复任、AI 终审确认）；代理期席位权重按"快照时点在任者=代理者"生效，原主权重失效——快照语义无需新机制。

### 4.2 换算公式（正式标定 ✔，结清 S2 §4.4 遗留）

**换算主公式**：

```
prestige_delta = round( raw_score × w_source )
声望净值(路) = Σ prestige_delta（旬内滚动累计）
```

- **统一量纲（REV-005 标定）**：`raw_score` 内含量纲常数 **K = 10**——`raw = K × Σ(w_dim × 净增量 × 时效系数)`，对策功/事功/军功/军策功统一适用（定义权在 S2 §4.4，本引擎为唯一换算出口）。**K 不作用于日常任务（TASK）来源**：日常任务按固定额度 **2-5 点/次（中位 3.5，v0.4 重标，原 1-3）** 直接入账再乘 w_source=0.9——防刷任务线性放大的同时保证纯执行通道成立。
- **权重标定哲学（v0.4 修订：决策与执行等价）**：**决策与执行都很重要，缺一不可**——文路（策功）与武路（事功/军功）总收益期望等价（双路 ≤10% 带宽不变），**非政治玩法（日常任务/执行/战斗/建设）的成长通道独立成立**：不上书也能正常升到大夫档（摄政资格线），只是少了政治高光（上卿/下卿仍需席位=政治参与）。
- **双画像验算基准（v0.4，替代原"旬均 150"单画像）**：纯执行玩家 ≈ 140/旬、政治活跃玩家 ≈ 185/旬——验算见 §4.3。

**路别来源权重表（w_source，v0.4 重标——决策与执行等价）**：

| 来源 | 文臣路权重 | 武将路权重 | 标定理由（v0.4） |
|---|---|---|---|
| 策功 STRATEGY_MERIT | **1.0**（文路主轴） | 0.7 | 定策是文路主轴；跨路折价保留转路资产语义 |
| 军策功 WAR_STRATEGY | **1.2** | 1.0 | 战时定策稀缺+策罪对称风险，溢价 20%（原 1.3，向等价导向收敛） |
| 事功 DEED | 0.7 | **1.0**（武路主轴） | 执行是武路主轴 |
| 军功 WAR_MERIT | 0.6 | **1.2** | 战争季节性溢价 20% 补偿机会成本 |
| 日常任务/执行贡献 TASK | **0.9** | **0.9** | **v0.4 重标（原 0.5）**：执行与战斗是并列的成长主干而非副业——纯执行玩家旬均达政治活跃玩家的 ~76%，大夫档旬差 ≤1 旬（§4.3 验算）；"不上书也能正常成长，只是少了政治高光" |

- **策功分原始值**（S2 §4.4 之 `strategy_score = K × Σ(w_dim × 净增量 × 时效系数)`）的维度权重标定：军事 1.2 / 民生 1.0 / 经济 1.0 / 外交 1.0 / 文化 0.8（军事高风险高回报）；时效系数：采纳后第 1 旬 1.0、第 2 旬 0.8（前瞻溢价）。
- **双修玩家**：两路声望分账独立维护，对外展示净值 = max(文, 武)（官阶只挂一路——GDD-0"官职一次只占一路一档"）。

### 4.3 散阶八档门槛表（v0.4 按双画像重验——决策与执行等价）

**双画像旬均验算（v0.4）**：

| 画像 | 构成验算 | 旬均 |
|---|---|---|
| **纯执行玩家**（不上书、不议政，专注任务/执行/战斗） | 45 任务/旬 × 中位 3.5 点 × w 0.9 = 142 | **≈ 140** |
| **政治活跃玩家（文）** | 任务 20 次 × 3.5 × 0.9 = 63 + 策功（2 次采纳 × raw 5.0 × K10 × w 1.0）= 100 + 杂项 25 | **≈ 185** |
| **政治活跃玩家（武）** | 任务 25 次 × 3.5 × 0.9 = 79 + 事功（raw 8 × K10 × w 1.0）= 80 + 杂项 25 | **≈ 185**（双路等价 G3 ✔） |

**大夫档达成旬差验算（修正一核心验收）**：700 ÷ 185 = **3.8 旬**（政治活跃）；700 ÷ 140 = **5.0 旬**（纯执行）→ **旬差 ≈ 1 旬，满足 ±2 旬带宽 ✔**。不上书的玩家正常升到摄政资格线，只是晚一旬、且上卿/下卿仍需席位（政治高光的合理溢价）。

| 档位 | 声望门槛 | 履历门槛 | 期望达成（v0.4 双画像） |
|---|---|---|---|
| 下士 | 0 | 注册 | 开局 |
| 中士 | 100 | 完成任务 ≥ 10 次 | 第 1 旬（双画像同） |
| 上士 | 300 | 完成任务 ≥ 30 次 | 第 2 旬 / 第 3 旬 |
| **下大夫** | **700** | 任官经历 ≥ 1 旬 或 策功/事功主轴来源累计 raw ≥ 200 | **政治活跃第 4 旬 / 纯执行第 5 旬（旬差 ≤1 ✔）——摄政资格线两画像均可达** |
| 中大夫 | 1100 | 职事/代理任职 ≥ 2 旬 | 第 6 旬 / 第 8 旬 |
| 上大夫 | 1500 | 同上 + 无未清偿策罪 | 第 8 旬 / 第 11 旬 |
| 下卿 | 1900 | 席位任职 ≥ 1 旬 | 赛季末 Top 层（席位=政治参与） |
| 上卿 | 2400 | 席位任职 ≥ 2 旬 | 满季巅峰（≈200/旬 含席位酬庸 50），天然稀缺（每国 ≤ 3 人） |

- 标定原则（v0.4）：**散阶主体通道（下士→上大夫）纯执行独立成立**；下卿/上卿绑定席位任职，是"政治高光"而非成长门槛——执行玩家不被迫上书，政治玩家多一条高光阶梯。

### 4.4 晋升/降级与功过抵扣

- **晋升**：双条件同时满足即晋（旬初结算，与朝会时点一致）；晋档配人格化演出（君主授衔诏）。
- **功过抵扣**：策罪/军策功负分**直接进声望流水扣减**（不做独立"罪账"二次折算——单一账本可追溯）；未清偿策罪（PENALTY 后声望净值仍低于当前档门槛）阻塞晋升（上大夫档硬条件）。
- **降级**：声望净值跌破档位门槛的 80% 且**连续 2 旬**无任官贡献 → 降 1 档（诏令公示，"功不抵禄"）；降级不低于中士（保留最低政治身份，与 S4 流亡"不删号"精神一致）。
- **转路折损衔接**（GDD-0 重转换定稿的数值落地）：转路时总声望折损 **10%**，另一路按（降 1 档后的档位门槛下限）就位；冷却 3 旬内两路熟练度加速失效（对齐 GDD-0 v0.2 补标）。

### 4.5 推举票机制

| 环节 | 规则 |
|---|---|
| **投票资格** | ① 大夫档以上；② 与候选人同国在籍（流亡者无票——S4 履历按国隔离延伸）；③ 近 2 旬活跃（完成 ≥5 次任务或 ≥1 次朝堂互动）——三条件缺一不可 |
| **一人一票** | 每次选举事件每玩家 1 票，投出即锁定不可改 |
| **计票** | 简单多数；得票须 ≥ 有票权者的 30% 方为有效当选（防低参与度小圈子窃位） |
| **AI 君主裁定** | 推举结果为**提名**，AI 君主终审任命：可依人格否决（恩怨账本有怨者/资历不足者），否决须附君心语录理由（可复盘）——A2 双通道的落地 |
| **防刷票** | ① 大夫档门槛天然隔离刷号；② 同设备/支付指纹簇投票整簇作废（风控联动 P7）；③ 票型全部入透明日志可查；④ 候选人自身政绩须达档位基准（下大夫档须策功/事功累计 ≥ 200），"只有人气没有政绩"者 AI 必否 |
| **选举节奏** | 席位补选：空缺后 1 旬内完成；摄政推举：季末结算期，票值入三重指标 |

### 4.6 跨季遗产折算

```
遗产分 = 0.5 × 赛季声望峰值 + 0.3 × 功过总量(策功+事功+军功+军策功) + 0.2 × 席位任职旬数 × 50
下季开局：初始档位 = 按遗产分对应门槛直接就位（不必从下士重爬）；
          初始声望 = 遗产分 × 0.5（注入起点，非白板）
```

- 跨季遗产按国隔离（S4 拍板规则延伸：换国籍不带走，原国遗产在原国复国/回归时恢复）。
- 名臣列传：赛季 Top10 策功/事功玩家自动入列传（对接"留名史册"授权，S1 §6.5）。

## 5. 玩家交互流程

| 场景 | 体验要点 |
|---|---|
| **晋升时刻** | 旬初朝会授衔诏（君主亲授、人格化评语——引用该玩家本季最亮眼的策功/军功归因链："卿上书劝农，粟溢三仓"）——晋升即 AI 君主"看见了你"的叙事时刻 |
| **席位任命/空缺** | 席位空缺全国公示（含前任去向：升任/免职/挂机请辞——免职原因透明）；任命诏+印绶演出（视觉锚点①青铜印信） |
| **廷议推举** | 推举廷议 = 候选人政绩时间线公展（自动聚合归因链，人人可查）→ 投票 → AI 终审诏（含否决理由）——选举全程是政治戏剧场 |
| **声望流水查询** | "官制典章"页：换算权重全公示 + 个人流水全可查（每笔声望可回溯到具体方略/任务/战功） |
| **降级/折损** | 降级诏公示但不羞辱（"暂削一级，以观后效"）；策罪扣减附君主语录（对称于策功表彰） |

## 8. 验证指标

### 8.1 核心指标

| 指标 | 定义 | 目标值 | 采集 |
|---|---|---|---|
| **席位竞争率**（G1） | 每次选举候选人数 / 席位数 | ≥ 2:1 | 选举日志 |
| **双路等价性**（G3） | 文/武路声望获取速率差异（同活跃投入分群对比） | ≤ 10%/旬 | 声望流水 |
| **纯执行通道健康度**（v0.4 新增） | 纯执行画像与政治活跃画像的大夫档达成旬差；纯执行玩家占比分布 | 旬差 ≤ 2 旬；占比无异常坍缩（若政治参与率下滑仅观察归因，不回摆权重） | 分群监控 |
| **晋升预期感**（G2） | "我知道怎么升官"问卷（5 分制） | ≥ 3.8 | 月度问卷 |
| **大夫档达成率** | 赛季中段（第 5 旬）活跃玩家中大夫档以上占比 | 15%-25% 带宽（摄政池深度） | 档位分布 |
| **AI 否决率** | 推举提名被 AI 君主否决的比例 | 10%-30% 带宽（全否=玩家的推举无意义；全准=AI 无主见，破坏支柱一） | S1 联动 |
| **遗产感知** | 遗产玩家次季首旬活跃 / 非遗产新玩家 | ≥ 1.3 | 分群对比 |
| **席位贡献健康度**（G4） | 席位在任者旬贡献达标率 | ≥ 80%（挂机清退兜底） | P4 监控 |

### 8.2 护栏指标

| 指标 | 阈值 | 说明 |
|---|---|---|
| 声望流水可追溯率 | 100% | G2 红线，缺源即事故 |
| 异常票作废处理 | 疑似刷票簇 100% 审计，作废有公告 | 选举公信力 |
| 换算权重变更 | 赛季内冻结（只可季间调，带审计+回归测试） | 防赛季中改规则引发公平性争议 |
| 档位金字塔形态 | 上卿人数 ≤ 3/国；上卿+下卿占比 ≤ 2% | 稀缺性失守即调门槛 |
