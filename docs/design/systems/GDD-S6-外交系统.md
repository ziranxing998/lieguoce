## 1. 系统概述

**一句话**：外交系统是《列国策》的**第二战场**——它维护国与国之间的关系值矩阵与外交动作集（照会/会盟/朝贡/斡旋/威胁），承载玩家经外交官职与"纵横玩法"（情报、欺诈、离间）参与的列国博弈，并向 AI 君主引擎持续供给第三层决策输入（外交事件流），使"合纵连横"成为不依赖战争的第二条国运路径。

**在整体中的位置**：
- 对**支柱二**：不战而屈人之兵、合纵改写秦统一——外交是"国运涌现"的非军事分支，历史引力命题（如合纵攻秦）的外交侧引擎。
- 对**玩家**：文臣外交线（行人/相邦席位 → 使节任务 → 照会起草 → 会盟谈判）是"文臣定策"在列国尺度的延伸；欺诈与情报是高风险高回报的纵横玩法。
- 它**不决定**宣战（S1 AI 独占终决，本系统提供理由与氛围）、**不裁决**会战（S3）、**不持有**恩怨账本（写入经 S1 M8）、**不计算**国力（外交收益走 S2 申报）。
- 数据流：本系统是 **S1 M2 第三输入层（diploma_events）的唯一生产者**，也是 S3 W8 暗战的规则宿主、S4 X6 合纵引力的数值载体。

```
[玩家外交动作/事件] → 【GDD-S6 外交系统】
                        ├─→ S1 M2：diploma_events（第三输入层，强依赖方）
                        ├─→ S3：宣战前置摩擦/斡旋/会盟援军
                        ├─→ S4：合纵引力（灭国戒备值）
                        ├─→ S2：外交维收益申报
                        └─→ S1 M8：恩怨账本（外交背叛/失信入账）
```

## 2. 设计目标与反目标

### 目标

| # | 目标 | 验证方式 |
|---|---|---|
| G1 | **外交影响战争与国运**：斡旋能化解宣战、会盟改变会战兵力对比、离间能拆散盟约 | 斡旋成功率带宽、会盟参战贡献量 |
| G2 | **关系可读可预期**：关系值档位、动作效果全部公示（"外交典章"），玩家可制定外交策略 | 关系面板渗透率、预期一致性问卷 |
| G3 | **纵横玩法有锋刃也有代价**：欺诈成功可改写局势，被检出必付恩怨与关系代价 | 欺诈成功率、检出后追责闭环率 100% |
| G4 | **事件流喂饱 AI**：外交事件使 S1 决策呈现"外交人格"（魏精算结盟、秦憎恶冗言照会） | S1 人格回归测试含外交场景 |
| G5 | **小国生存玩法特权落地**（GDD-0 §七）：弱国凭外交手段可求存 | 弱国非战化解宣战案例率 ≥ 60% |

### 反目标（本系统明确不做的事）

| # | 反目标 | 理由 |
|---|---|---|
| A1 | **关系不可用数值购买**：国库/资源可馈赠，但馈赠效果经关系值规则折算、有边际递减，不存在"氪金亲善"按钮 | 对齐 S5 A1（政治资本不可代购）与 S2 A3 |
| A2 | **玩家不代行国家宣战/缔约终决**：宣战 S1 独占（GDD-0 4.3）；盟约缔结须 AI 君主终审（人格+恩怨裁定） | 外交是君主的意志在列国间的延伸，玩家是"纵横家"不是"元首" |
| A3 | **不做即时全球外交聊天**：外交动作收敛为结构化动作集+旬度事件节拍（自由对话仍走 L3/L4 三场合） | 节奏化决策定稿 ✔；无结构外交不可审计 |
| A4 | **关系不黑箱**：无隐藏好感度、无暗箱修正；AI 君主的"态度"差异全部来自人格卡对同一关系值的不同解读 | 可解释性对齐君心参悟与透明日志原则 |
| A5 | **欺诈不做成无成本陷阱玩法**：欺诈必留痕迹（检出概率>0）、被检必追责（恩怨入账） | 防止外交沦为社工骚扰工具；保护休闲玩家 |

## 3. 系统拆解（7 子模块）

| 模块 | 职责 | 输入 | 输出 |
|---|---|---|---|
| D1 国家关系值矩阵 | 七国两两关系值 [-100,+100] 与档位维护 | 外交动作、事件流、自然回归 | 关系档位（全系统消费） |
| D2 外交动作集 | 照会/馈赠/威胁/朝贡/斡旋/会盟邀请的执行与效果结算 | 玩家动作（权限校验经 S5 席位） | 关系值增量、S2 收益申报、事件入流 |
| D3 外交官职与使节玩法 | 行人席位权限、使节任务线（递送/谈判/驻外） | S5 席位、任务系统 | 外交声望贡献（→ S5 换算）、动作资格 |
| D4 情报与欺诈（V1） | 虚报军情/离间/假照会：成功判定、检出与追责 | 玩家动作、情报值（S3 间谍线） | 欺诈效果/检出事件（恩怨入账） |
| D5 会盟机制 | 双边/多国临时联盟：谈判→缔约→存续→背约 | D2 动作、AI 终审 | 盟约状态（S3 援军）、背约恩怨 |
| D6 外交事件流接口 | 一切外交结果的标准化事件产出，喂 S1 M2 | D1-D5 全部输出 | `diploma_events`（schema 见 §4.4） |
| D7 关系衰减与修复 | 向中立的自然回归、失信修复路径（赔礼/履约/共同作战） | 时间、修复动作 | 关系值修正 |

### 3.1 D1 国家关系值矩阵

- 七国两两 21 对关系值，区间 [-100, +100]，五档（§4.1）。
- 关系值是**国家间**数值；AI 君主对具体关系值的**解读**由人格卡完成（同一"-30 冷淡"，魏"精算"型视为可交易、韩"忧患"型视为危险信号）——数值中立、人格着色（A4）。

### 3.2 D2 外交动作集

六动作（V1 全量；MVP 三个）：**照会**（表态/抗议/贺喜——低成本姿态）、**馈赠**（资源换关系，边际递减）、**威胁**（以摩擦/军力为筹码，失败反噬）、**朝贡**（弱对强的定期输诚，换保护预期）、**斡旋**（第三方调解冲突，S3 斡旋卡的正式化）、**会盟邀请**（D5）。

### 3.3 D3 外交官职与使节玩法

- 行人席位（S5 V1 席位）：照会起草与谈判主导权、欺诈豁免审查权（对使节欺诈的检出加成）。
- 使节任务线：递送国书（L1 布衣可接的最低门槛外交任务）→ 随团出使（L2）→ 主谈/驻外（行人/相邦）——外交参与阶梯与官职阶梯同构。
- 相邦（文席之首）：会盟全权谈判资格（MVP 中外交主权限载体）。

### 3.4 D4 情报与欺诈（纵横玩法，V1）

三类：**虚报军情**（夸大/隐瞒军力影响他国 AI 裁定）、**离间**（伪造照会/散布谣言拆散他国盟约）、**假承诺**（以假许诺换眼前利益）。判定与追责见 §4.5——有锋刃（成功可改写 S1 决策输入）、有代价（检出→GRUDGE 入账+关系惩罚+行人审查加成）。

### 3.5 D5 会盟机制

- 形态：双边盟约（互不侵犯/互保）与多国合纵（针对特定威胁的临时联盟——S4 合纵引力的承接器）。
- 盟约效用：会战援军（S3 W3）、威胁动作筹码加成、朝贡减免。
- 缔结：玩家谈判（达到意向条款）→ 双方 AI 君主终审（人格+恩怨账本：背约者同盟邀请自动降权）→ 缔约诏（双方同刻发布，仪式感事件）。
- 背约：单方退出/违约 → 对方关系值重挫 + **PLEDGE 承诺类硬记忆**（REV-WRITEBACK 修订：跨文档一致性——拼写对齐 S1 §3.8/§4.3 枚举 `PLEDGE`，原"PLEDGE"为笔误，下同；S1 M8：AI 必须履约或"背约记账"——背约者在他国君主处留下跨季失信记录）。

### 3.6 D6 外交事件流接口（S1 契约）

所有外交结果标准化为事件入流（§4.4 schema），S1 M2 按旬窗口聚合。**这是本系统最重要的下游契约**：S1 的"外交人格"（秦按关系值冷热决策、燕利用情报落差）完全依赖本流的质量与节奏。

### 3.7 D7 关系衰减与修复

自然回归（见 §4.1）+ 修复动作：赔礼（馈赠特例，修复 GRUDGE 类关系）、履约（连续履约积累"信用分"）、共同作战（盟约内并肩会战一次 +10）。修复防"一次背约永久死档"——但 PLEDGE 硬记忆中的失信事实永在（语录会提，对齐 S1 释怀红线"永不装作无事"）。

## 4. 数据规格

### 4.1 关系值区间与衰减参数（首版标定 ▲）

| 档位 | 区间 | AI 解读示例（韩·忧患型） | 自然回归 |
|---|---|---|---|
| 敌对 | ≤ -60 | "虎狼在侧，寡人夜不能寐" | 0（锁死，需修复动作） |
| 冷淡 | -59 ~ -20 | 边备之 | +3/旬 向 0 |
| 中立 | -19 ~ +19 | 可使往来 | 0 |
| 友好 | +20 ~ +59 | 可与共谋 | -2/旬 向 0 |
| 盟约 | ≥ +60 且缔约 | "唇齿之交" | 0（由盟约状态机管理） |

- 馈赠边际递减：单旬对同一国馈赠效果 = base × 0.7^(n-1)（复用 S2 递减形态，防氪金亲善，A1）。

### 4.2 动作-效果表（V1）

| 动作 | 权限 | 关系效果 | 附加效果 | 失败/反噬 |
|---|---|---|---|---|
| 照会 | 使节任务/行人 | ±2~5 | 事件入流（S1 态度采样） | 无（低成本姿态） |
| 馈赠 | 士以上 | +5~15（递减） | S2 经济维消耗申报 | — |
| 威胁 | 行人/相邦 | -10~20 | 成功：对方让步事件（S1 采样） | 失败：-15 + 对方动员倾向↑（喂 S1 主战氛围） |
| 朝贡 | 君主 AI 裁定 + 相邦执行 | 弱→强：+10/旬（存续期） | S2 经济维流出；强方"保护预期" | 停贡：-25 + 硬记忆 GRUDGE |
| 斡旋 | 行人/相邦（持节杖） | 双方各 +5（成功） | 化解 S3 宣战/会战（见 §4.3） | 失败：斡旋信誉 -1/次 |
| 会盟邀请 | 相邦 | 缔约后锁定盟约档 | D5 | 见背约规则 |

### 4.3 斡旋成功判定（正式化 S3 MVP 临时规格，取代映射已注记 GDD-0 §九）

```
斡旋成功条件（S3 §4.2 简化版的正式版）：
  relation(斡旋方, 冲突双方) 均 ≥ 友好档(+20)
  且 AI 君主"台阶"达成：按对方人格卡给了可下的台阶
    （秦·法术势：需实质利益补偿；楚·浪漫：需颜面台阶；韩·忧患：重礼即可）
  且 被斡旋方 AI 终审通过（恩怨账本无锁死 GRUDGE：敌对档不可斡旋）
成功效果：S3 会战实例 CANCELLED / 宣战意向撤回；斡旋方军策功 = 避免损失折算（S2 §4.5 战时例外条款口径）
```

### 4.4 外交事件 schema（喂 S1 M2，扩展自 S1 §4.2 `diploma_events`）

```json
{
  "event_id": "dip_x14_033",
  "type": "ALLIANCE_FORMED",          // SEE_NOTE / GIFT / THREAT / TRIBUTE / MEDIATION / ALLIANCE_FORMED / ALLIANCE_BROKEN / BETRAYAL_RUMOR(V1)
  "from": "wei", "to": "han",
  "relation_delta": {"han_wei": +18},
  "stance_payload": {"threat_level": 2, "demand": " cease_support_qin"},
  "recency_d": 1,
  "ai_relevance": ["war_intent", "alliance_option"]   // 提示 S1 该事件相关的决策面
}
```

- 与 S1 §4.2 既有字段对齐：`type/from/count/recency_d` 保留，新增 `relation_delta` 与 `ai_relevance`（提示 S1 该喂给哪类决策，防无关事件稀释 prompt）。
- 旬窗口聚合规则不变（S1 M2）。

### 4.5 欺诈成功判定规则（V1）

```
欺诈成功率 = base(类型) × 技能系数(纵横熟练度) × 情报差系数(对方对己方情报可见度反向)
  base：虚报军情 0.5 / 离间 0.35 / 假承诺 0.6 ▲
检出概率 = 0.2 + 行人席位审查加成(0.1/名) + 受害方情报投入加成（上限 0.8）
被检后果：关系 -20~35 + 恩怨账本 GRUDGE（软，intensity 0.6）+ 君主语录点名
          + 欺诈者个人声望 -50（PENALTY 入 S5 流水，可追溯）
成功效果：S1 决策输入被污染（假军情入库，靠对立情报纠正）——欺诈的本质是给 AI 喂假数据
```

- 设计要点：欺诈**成功**也留痕（检出概率永 >0），且"喂假数据"作用于 AI 决策输入而非直接改关系值——玩家可反制（投入情报清洗），形成情报攻防（G3）。

### 4.6 会盟状态机

```
PROPOSED ──双方 AI 终审通过──→ ACTIVE ──期满/协商退出──→ EXPIRED
   │                              │
   └──任一方 AI 否决──→ REJECTED   └──单方违约──→ BROKEN（背约方硬记忆+关系重挫）
```

- ACTIVE 有有效期（8 旬/季内），续约需重新谈判；多国合纵同构，另含"共主"推定（召集国）。

## 5. 玩家交互流程

| 层级 | 外交参与面 | 要点 |
|---|---|---|
| **L1 布衣** | **递送国书**（最低门槛外交任务：跨国跑腿+小事件抉择，外交声望 1-2 点/次）、商队过境护送 | 布衣也能"为邦交出力"——外交不是高官专属；国书送达有仪式演出（对齐视觉锚点②） |
| **L2 士/门客** | 随团出使（谈判事件中的结构化选项：附议/进言）、馈赠执行、民间往来任务（互市/学宫交流，友好档微贡献） | 外交声望的攒台阶阶段 |
| **L3 文臣（行人/相邦）** | 照会起草（结构化：立场+诉求+筹码，AI 君主过目后以诏令发出）、威胁与斡旋主谈、欺诈策划（V1）、会盟谈判 | 谈判以"结构化回合"呈现：我方条款 ↔ 对方 AI 回应（人格化）↔ 调整再谈，全部留档可复盘 |
| **L4 摄政** | 廷议外交议题发起（每旬 1 次权限的常驻用例）；战时斡旋卡（S3 W4，走本系统 §4.3 判定） | 外交是摄政定策权的高光场景 |

**关键体验时刻**：缔约双诏同刻发布（两国玩家同见，合纵的仪式感）；离间成功的"借刀杀人"复盘（V1：透明日志显示假照会如何污染了 AI 决策——欺诈可被讲述）。

| S1 AI 君主引擎 | 盟约/朝贡/威胁的 AI 终审（事件决策）；恩怨账本读写 | 终审理由=外交人格的出口 | 强依赖 |

| 风控系统 | 设备簇 | 欺诈防滥用（同簇高频欺诈限流） | 中依赖 |

### 6.2 下游服务

| 系统 | 数据 |
|---|---|
| S1 M2 | `diploma_events`（第三输入层，唯一生产者） |
| S1 M8 | 外交失信 GRUDGE / PLEDGE 硬记忆条目 |
| 史书系统 | 盟约始末、合纵史诗素材 |
| S2 | 外交维国力的主要供给源 |

### 6.3 不做越界

- 不决定宣战/停战（S1 独占）。
- 不直接改他国国力（威胁成功 = 对方 AI 获得让步倾向输入，非数值剥夺）。
- 不持有 S4 灭国判定结果（只消费事件）。

## 7. MVP 裁剪（3 国情形）

| 模块 | MVP 实现 | 砍掉/简化 | 恢复时机 |
|---|---|---|---|
| D1 关系值矩阵 | **实装**（3 国 3 对关系，五档+自然回归全量——矩阵是 AI 决策质量的地基，不简化） | — | — |
