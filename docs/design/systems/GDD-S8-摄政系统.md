## 1. 系统概述

**一句话**：摄政系统是"君臣共治"支柱的**顶点接口**——它管理摄政位的产生（三重指标竞选）、任期（就任/卸任/弹劾/收回）、四项可干预权限的执行、威望值政治资本，以及与 AI 君主的廷议仲裁，让玩家真正"与君主共治一国"而不沦为第二君主。

**在整体中的位置**：
- 对**支柱三**：布衣→士→卿大夫→摄政的政治参与阶梯，摄政是塔尖——玩家的政治能力第一次**直接改写世界运行参数**（任务潮排序、动员节奏、封赏分配）。
- 对**支柱一**：摄政是 AI 君主人格的**最大压力测试场**——君主面对一个会顶嘴、会强推、会被弹劾的玩家副手，"活的"程度被逼到极限；AI 立场分与反对理由语录是君心的最高强度展示窗。
- 对**玩家主权原则**：摄政可干预域内，摄政的手动裁决 > 其客卿代行（铁律适用）；但**摄政在位期间的决策权动作本身不可代驾**（S7 A6）——这是主权原则的边界案例：你可以派客卿替你拉票竞选，但不能派它替你当摄政。
- 它**不拥有**宣战终决/引力/人格卡（AI 独占域）、**不执行**任务潮生成（S1 M5 只收其优先级覆盖）、**不计算**政绩与声望（S5 供数）。

```
[S5 三重指标/推举票] → R1 竞选 → 【摄政系统】 → R3 执行器 → S1 M4/M5/S2/S6（四权限落地）
[GDD-0 4.3 双清单]  →        │        ├─→ R5 廷议 ←→ S1 M6（AI 立场分+君心理由）
[S7 主权边界]       →        │        ├─→ R4 威望值 → S5 声望遗产
                              ↓        └─→ R7 印绶收回 ←→ S2 国力负增长检测
                     透明日志（全国可查，复用 B7）
```

## 2. 设计目标与反目标

### 目标

| # | 目标 | 验证方式 |
|---|---|---|
| G1 | **共治真实成立**：摄政的干预能被玩家群体感知到世界变化（"这旬任务潮不一样了"） | 摄政上任前后任务潮排序变化感知问卷 ≥ 3.5 |
| G2 | **君臣张力可玩**：廷议/威望强推是有策略深度的博弈（分歧越大代价越高），不是盖章流程 | 威望强推使用率、胜率带宽 |
| G3 | **制衡透明可复盘**：弹劾/收回/否决全程全国可查、理由可读（AI 理由=君心语录） | 透明日志完整率 100% |
| G4 | **败者也体面**：卸任/被收回/弹劾下台不等于社会性死亡，保留政治生涯出路 | 卸任摄政者次旬留存 ≥ 全服均值 90% |
| G5 | **暴政有解**：四重制衡（威望/弹劾/AI 收权/透明）使暴政摄政的平均危害期 ≤ 2 旬 | 暴政案例（模拟+内测）危害期统计 |

### 反目标（本系统明确不做的事）

| # | 反目标 | 理由 |
|---|---|---|
| A1 | **摄政不是第二君主**：不可干预 AI 独占域（宣战终决/引力/人格卡/摄政规则本身），无双摄政、无摄政世袭 | GDD-0 4.3 双清单定稿；架空君主=支柱一崩塌 |
| A2 | **AI 君主不可被架空**：任何摄政动作都有 AI 知情与表态通道（立场分+理由），不存在"绕开君主的暗箱执政" | 支柱一：共治是博弈不是接管 |
| A3 | **摄政不可被代驾**（主权原则边界案例）：在位期间的提案、威望强推、干预参数设定**仅限手动**（S7 白名单硬拒绝）；客卿可替其**竞选**（拉票/政绩积累），不可替其**执政** | 执政责任的人格不可让渡；与"AI 独占"同构的政治安全红线 |
| A4 | **不搞多数人暴政替代品**：弹劾需 30% 卿大夫联署+廷议过半，联署不可由客卿代签（联署是身份基座行为） | 防止客卿集群伪造民意 |
| A5 | **不做无代价否决权**：摄政对 AI 的对抗永远消耗威望（政治资本有限）——分歧必须有价格 | 无限对抗使共治退化为拉锯杂音 |

### 3.1 R1 摄政位产生与竞选

- **时机**：赛季末结算期（GDD-0 4.3），任期=下一整季。
- **资格**：大夫档以上（GDD-0 拍板门槛）、本国在籍、履历按国隔离（原国履历不计）。
- **三重指标**（同表不同口径，S5 供数）：**政绩**（策功+事功+军功聚合，文臣=策功、武将=事功，▲聚合权重待 S5 Q4 结案）、**声望**（峰值档口径）、**推举票**（S5 §4.5 廷议推举，AI 终审否决权保留）。
- **文武皆可，风格差异**（GDD-0 v0.2）：文臣摄政偏"任务潮优先级+廷议议题"（定策面），武将摄政偏"动员节奏+封赏比例"（执行面）——权限总量不变，侧重不同（R3 参数化）。
- **次席**：排名第二者就任次席（候选/制衡），职权=弹劾发起权+摄政缺位代理（代理期间权限打七折 ▲，防次席"盼摄政出事"的畸形激励——代理期政绩计入考评但代理不升正）。

### 3.2 R2 任期与就任/卸任

- **就任**："拜印大典"演出（对齐视觉锚点①青铜印信）+ AI 君主人格化授印诏（对新摄政的期待与警告——按人格：秦"勿使寡人失望"、齐"愿与卿共治一方"）。
- **卸任四出口**：①期满（正常交接，政绩入跨季遗产）；②弹劾通过（R6）；③AI 收回印绶（R7）；④威望耗尽自动下台（R4）。四出口各有独立的人格化退场演出（见 §5）。
- 就任/卸任时点 = 旬初朝会（快照语义对齐：旬内换摄政不影响本旬已冻结决策，新摄政权限自下一旬生效）。

### 3.3 R3 可干预域执行器（四权限）

| 权限 | 执行机制 | 系统落点 | 文/武侧重差异 |
|---|---|---|---|
| 任务潮优先级排序 | 指定任务池内主推方向排序（**不改 S1 人格偏置权重底数**——S1 M6 既有边界） | S1 M5 | 文臣侧重（+1 次可排序目标 ▲） |
| 战时动员令节奏 | 设定集结期动员配比与事件决策合并窗口参数 | S3 W2/M4 | 武将侧重 |
| 俸禄/封赏分配比例 | 设定军功/文功封赏池比例滑杆（限区间 30%-70% ▲） | 经济/俸禄系统 | 武将侧重 |
| 廷议议题发起 | 每旬 1 次发起权，走 R5 廷议流程 | S1 M6 | 文臣侧重（军议议题战时 +1 次 ▲） |

- **参数校验**：全部干预在预设区间内（防暴政的第一道软约束）；越界参数网关直接拒绝。
- **玩家主权落点**：四权限全部**仅限手动**（A3）。

### 3.4 R4 威望值系统（政治资本）

- **定位**：威望 = 摄政对抗 AI 君主与推行意志的**有限政治资源**——它让"分歧有价格"，是防暴政的核心经济手段（与声望独立：声望是全国声望，威望是君臣关系内的授信）。
- **收支表（首版标定 ▲）**：

| 类别 | 数值 | 说明 |
|---|---|---|
| 就任 | **+100** | 初始授信 |
| 每旬政绩结算 | +10（国力综合旬环比非负 且 任务潮响应率达标） | 治理有方则资本滚存 |
| 廷议胜诉（强推成功且国力改善） | +15 | 事后验证：赌对了有奖励 |
| 提案被否后主动撤回 | +2 | 体面让步的小额补偿（鼓励止损不鼓励死磕） |
| **强行推行消耗** | **base 10 + \|AI 立场分\| × 8** | 立场 -5（君主强烈反对）→ 消耗 50；立场 0 → 10。**分歧越大越贵**——玩家可从消耗量反推君心强度（与君心参悟闭环） |
| 威望耗尽（< 0） | **自动卸任** | "印绶暂摄"退场（④出口） |

- 威望**不结转、不交易、不可代行充能**（充能靠政绩=本人执政成绩）。

### 3.5 R5 廷议仲裁流程

```
摄政提案（R3 议题发起 或 强推某决策） 
  → S1 M6：生成 AI 立场分（-5~+5）+ 反对理由（君心语录形式，M7 双审）
  → 摄政抉择：撤回（+2 威望） | 强行推行（扣威望，base10+|立场|×8）
  → 执行 → 结果归因（2 旬窗口）→ 胜诉/败诉结算（+15/追责语录）
  → 全程入透明日志（提案原文↔AI 立场↔威望消耗↔国力结果，四段可查）
```

- 立场分为负但威望充足时仍可强推——**共治不是服从，是有价格的对抗**（A5 反向表述）。
- AI 立场分生成受人格卡支配（魏精算型给立场快而准、楚浪漫型易被豪言打动）——同一提案在不同国的命运不同，这是"国格差异"的玩法化。

### 3.6 R6 次席制衡与弹劾

- **弹劾流程状态机**：`IDLE → 联署期（次席发起 + 30% 卿大夫联署，7 天）→ 廷议（有票权者投票）→ 过半通过 = 免职+威望清零+“失印”史痕 ｜ 否决 = 摄政威望 +10（经受住弹劾的信用奖励）→ IDLE`。
- 联署是身份基座行为（**不可客卿代签**，A4）；同一摄政每季最多被弹劾 2 次（防骚扰性弹劾）。
- 弹劾理由必填（结构化枚举：暴政/无能/叛卖/其他+陈述），全国可查。

### 3.7 R7 印绶收回与透明查阅

- **收回触发**：S2 检测**国力综合指数连续两旬负增长**且摄政任内 → AI 君主发起收回（事件决策，人格化诏令：收回理由引国力事实但不暴露数值——"卿秉政两旬，仓廪日虚"）。
- **收回是 AI 制衡的最后一闸**：不受威望/弹劾约束（君主独断），但收回理由全国可查、可被玩家复盘评价——AI 滥收回会损耗君主"公信"（观察指标，远期接入君主声望系统 ▲）。
- **透明查阅**：摄政全部干预、威望收支、廷议记录赛季内全国可查（复用 B7），跨季匿名化（S1 §6.5）。

### 3.8 R8 战时摄政

- 战时增强（S3 联动）：动员节奏权限生效范围扩大（集结期+会战窗口）、封赏滑杆临时上限放宽（30-80% ▲）、军议议题 +1 次（文臣侧）。
- 战时政绩单独记账（军策功/动员完成度），战败不自动追责摄政（战争是君主决定，AI 独占宣战的责任对称性）——但**战时暴政**（强推失败连续 2 次）威望消耗 ×1.5 ▲。

## 4. 数据规格

### 4.1 摄政状态机

```
CANDIDATE ──竞选胜出──→ IN_OFFICE ──期满──→ EXPIRED（政绩入遗产，可再竞选）
                            │
                            ├──威望耗尽──→ STEPPED_DOWN（"印绶暂摄"）
                            ├──弹劾通过──→ IMPEACHED（"失印"，威望清零）
                            └──AI 收回──→ RECALLED（人格化退场，威望半数转声望遗产）
```

| 字段 | 类型 | 示例值 | 说明 |
|---|---|---|---|
| `regent_id` / `nation` / `season` | string | `"regent_qi_s1"` | 每国每季 1 摄政+1 次席 |
| `state` | enum | `"IN_OFFICE"` | 上图五态 |
| `regent_player` / `deputy_player` | string | | |
| `track_focus` | enum | `"WEN"` / `"WU"` | 文臣/武将侧重（权限参数化） |
| `took_office_xun` / `term_end_xun` | 旬号 | | 快照语义锚点 |
| `prestige` | float | `100` | 威望余额（R4） |
| `impeach_count` | int | `0` | 每季上限 2 |
| `recall_watch` | object | `{neg_streak: 0}` | 国力负增长连续旬计数（R7 触发器） |

### 4.3 弹劾流程字段

`{impeach_id, initiator(次席), signatures:[player_id]（联署率≥30%）, reason_enum, statement, vote_window, votes:{for, against}, outcome, xun}`——联署与投票均为身份基座行为（仅限手动）。

### 4.4 威望收支流水

复用 S5 声望流水结构，`source_type` 增 `PRESTIGE` 域（`TAKE_OFFICE` / `GOV_BONUS` / `TINGYI_WIN` / `WITHDRAW_REFUND` / `FORCE_COST` / `IMPEACH_CLEAR`）——账本同构，审计同管线。

## 5. 玩家交互流程（五视角）

| 视角 | 关键路径 | 体验要点 |
|---|---|---|
| **竞选者** | 政绩时间线自动聚合（归因链公展）→ 廷议拉票 → AI 终审授印 | 竞选 = 政绩的公开检阅（数据自己会说话）；AI 否决须附君心理由 |
| **在任摄政** | 旬初设干预参数（四滑杆）→ 廷议议题 → 面对 AI 立场分抉择（撤回/强推）→ 旬末看政绩结算与威望余额 | **"撤回还是强推"是摄政每旬的核心抉择**——AI 反对理由的措辞强度（君心）是决策信息 |
| **次席** | 监督 + 弹劾发起权 + 缺位代理（七折权限） | 制衡者的戏剧位置："最希望国家出事的人不能得利"——代理不升正 |
| **普通卿大夫** | 联署弹劾、廷议投票（有票权者）、旁观透明日志 | 中层是制衡的群众基础——30% 联署让"卿大夫阶层"真实有政治重量 |
| **布衣** | 看诏令变化感知摄政存在、透明日志吃瓜 | 摄政是可见的："这旬任务潮变了，是新摄政的手笔" |

**"被收回印绶"的体验设计（G4：败者也体面）**：收回/弹劾/耗尽三出口均配人格化退场演出——AI 君主诏令**先肯定贡献再述免职理由**（秦："卿强推河工，志可嘉，然仓廪日虚，印绶暂收，赐金二十"）；威望半数转声望遗产（RECALLED）/ 全额清零仅限弹劾（IMPEACHed 是罪罢）；卸任者可再竞选、可转武路、可入次席——政治失败是剧情，不是惩罚。

## 7. MVP 裁剪

### 7.1 既有定稿基线（GDD-0 §九）

齐国试点 1 席位、权限限"任务潮优先级+威望值机制"、弹劾简化为威望耗尽自动下台。

### 7.2 MVP 模块对照与廷议最小版建议

| 模块 | MVP 实现 | 砍掉/简化 |
|---|---|---|
| R1 竞选 | 实装（三重指标+推举票，S5 已实装口径） | 文武侧重差异（MVP 单一参数组） |
| R2 任期 | 实装（旬快照语义+期满出口） | 就任大典演出 → 诏令文本 |
| R3 执行器 | **2 项权限**：任务潮优先级 + 威望值强推（既有定稿） | 动员节奏/封赏滑杆/军议加次 |
| R4 威望值 | **实装全收支规则**（含分歧定价公式）——威望是 MVP 摄政验证的核心仪表 | — |
| R5 廷议 | **最小版恢复建议（✔）**：AI 立场分+反对理由语录（复用 M6+M7，边际成本≈0），**不恢复**廷议集会演出与投票环节（威望不足直接否，既有定稿） | 集会演出/投票流程 |
| R6 弹劾 | 简化为威望耗尽自动下台（既有定稿）；次席不设 | 全部弹劾流程 |
| R7 收回 | 触发检测实装（负增长计数），收回演出 → 诏令文本 | 公信观察指标 |
| R8 战时摄政 | 砍（MVP 单场剧本会战，摄政战时权限无生存场景） | V1 |

**廷议最小版建议理由**：① M7 语录管线 MVP 已上线，AI 反对理由的边际成本≈0；② 无 AI 理由的威望强推=纯数值扣减，玩家无法理解"为何贵、贵多少意味着什么"——**分歧定价必须配合分歧理由才构成博弈**，否则 G2（君臣张力可玩）在 MVP 即失败；③ 投票/集会仍砍，节奏与成本不破既有定稿。

### 7.3 MVP 验证映射

齐国（摄政）vs 秦楚（纯 AI 对照）A/B 不变；新增度量=威望强推使用率与胜诉率（G2 在 MVP 的最小验证）。

## 8. 验证指标

### 8.1 核心指标

| 指标 | 定义 | 目标值 | 采集 |
|---|---|---|---|
| **竞选参与率** | 每季竞选候选人数 / 席位数 | ≥ 2:1（对齐 S5 G1） | 选举日志 |
| **任期存活曲线** | 摄政任期中位长度 / 满任期 | 中位 ≥ 60%（太短=制衡失衡，太长=无张力） | 状态机日志 |
| **威望强推使用率** | 发起强推的摄政旬占比 | 20%-50% 带宽（不用=傀儡，滥用=暴君训练场） | R4/R5 |
| **强推胜诉率** | VINDICATED / FORCE | 30%-60%（同斡旋带宽逻辑） | 归因窗口结算 |
| **弹劾触发率**（V1） | 每季弹劾事件数/国 | ≥1 次国占比 20%-40%（有牙齿但不常拔） | R6 |
| **收回印绶率** | 每季 AI 收回数/国 | 0-15%（>15%=AI 过苛或政绩门槛过严） | R7 |
| **廷议参与率**（V1） | 弹劾廷议有票权者投票率 | ≥ 60% | R6 |
| **共治体验调研** | "摄政让我感到与君主共治而非打工"（5 分制） | ≥ 3.8 | 季度问卷 |
| **A/B 对照** | 齐国 vs 秦楚的活跃留存/上书率差 | 摄政国正向显著 | 既有 MVP 设计 |

### 8.2 护栏指标

| 指标 | 阈值 | 说明 |
|---|---|---|
| 卸任者次旬留存 | ≥ 全服均值 90% | G4 败者也体面 |
| 暴政危害期 | 从暴政行为到被制衡（耗尽/弹劾/收回）的平均旬数 | ≤ 2 旬（G5） |
| 透明日志完整率 | 摄政行为可追溯率 100% | G3 红线 |
| 代行侵权 | 摄政在位决策类的客卿代行通过数 | = 0（S7 网关硬拒绝，一票否决） |
| 收回理由合规 | 收回诏令含可读理由的比例 | 100%（AI 滥收回=君主公信事故） |
