## 1. 系统概述

**一句话**：高位离席与代理系统解决"身居高位的玩家长时间不上线，国家政治谁来管"——以先秦**告归**（告假）与**代摄**（太子监国、卿佐代政）文化为原型，建立"主动告假→失期代理→印绶暂摄→体面回归"的完整阶梯：**公职离席由玩家对玩家的代理承接（人的代理，不是 AI 的代行），AI 君主只做最后兜底**。

**问题场景与解法映射**：
- 摄政位空转（四权限无人执行）→ 次席**代摄**（七折权限）；
- 席位悬置（稀缺官位被离线者占用）→ AI 君主暂收+补选，原主保留**复任优先权**；
- 与客卿体系的边界 → **代理 = 人对人**；守舍之约不覆盖公职职责——客卿只管玩家私产，不管国家公器（主权原则推论④的边界澄清）。

**文化佐证**：李斯"告归咸阳"是先秦真实的告假制度；周公摄政、太子监国、卿佐代政是"代摄"的政治传统——离席有制、代摄有名、归政有礼，本系统把这套礼制做成玩法。

## 2. 设计目标与反目标

### 目标

| # | 目标 | 验证方式 |
|---|---|---|
| G1 | **政治不停摆**：摄政/席位离线期间国家机器持续运转，空转期 ≤ 1 旬 | 摄政位空转率（§8.1） |
| G2 | **离席不摧毁投入**：告归/被代理/被暂摄不没收跨季资产（履历/遗产/恩怨全保留），回归有体面通道 | 回归玩家留存与复任率 |
| G3 | **代理有制衡**：代理行为全透明标记，代理不得变相夺位、不产生"影子摄政" | 代理转正率 = 0（规则性禁止）、影子摄政案例 = 0 |
| G4 | **主权原则自洽**：代理=人对人，与守舍之约（AI 代行私产）边界清晰无混淆 | 边界申诉率 ≈ 0 |
| G5 | **敌国博弈成立**：离席信息透明公开，"趁虚"成为合法战略信息 | 离席状态查询渗透率 |

### 反目标（本系统明确不做的事）

| # | 反目标 | 理由 |
|---|---|---|
| A1 | **不惩罚到摧毁跨季投入**：失期只动公职（席位/印绶），不动个人资产（声望/履历/恩怨/家族/客卿） | 现实离线是生活； destroyed players don't return，违背复国线与遗产承诺 |
| A2 | **代理不得变相夺位**：代理摄政不可发起对原主的弹劾（利益冲突）、代理期不计入"席位任职"履历门槛（防"盼出事"激励）、代理不升正 | S8 Q4 方向的刚性化 |
| A3 | **不允许影子摄政**：长期离线者挂名吃俸不存在——失期即停俸，阶梯到期公职必动 | 挂名高位是政治停摆与公平双重毒药 |
| A4 | **AI 不做默认接管者**：AI 君主只在失期阶梯尽头（暂摄）与国力危机（S8 R7 收回）出手——日常空缺由人代理，AI 兜底 | AI 全面接管=支柱三反向坍塌（国家自动运转，玩家政治无意义） |
| A5 | **离席信息不隐瞒**：告归/失期/代摄状态全国公开可查（透明日志原则的自然延伸） | 隐瞒不可实现（行为可观测）且损失"趁虚"战略玩法 |

## 3. 系统拆解（6 子模块）

| 模块 | 职责 | 输入 | 输出 |
|---|---|---|---|
| X1 离席判定与告归制 | 告假申请（旬为单位）、失期判定 | 玩家申请、在线记录 | 离席状态（进状态机） |
| X2 梯次代理 | 摄政：次席自动代摄（七折）；席位：AI 君主暂收+补选 | 失期事件 | 代理关系（→ S1 seat_influence、S8） |
| X3 印绶暂摄与让贤 | 失期阶梯尽头：摄政罢免/席位重选，回归体面通道 | 失期时长 | 暂摄事件、复任优先权登记 |
| X4 代理制衡 | 代理行为透明标记、代理威望独立授信、代理不可弹劾原主 | 代理动作 | 审计流水、威望账目 |
| X5 回归交割 | 原主回归→代理结束→账目交接（复用守舍回禀模式） | 上线事件 | 交割报告、复任/重选流程 |
| X6 客卿边界澄清 | 守舍之约不覆盖公职（AI 管私产不管公器）的边界执行 | — | S7 白名单校验联动 |

### 3.1 X1 离席判定与告归制

- **告归（主动告假）**：以旬为单位申请（"臣告归一旬"），提前一旬申请、写明事由（不必真实、叙事化即可）；**上限：连续 ≤2 旬、每季累计 ≤4 旬** ▲。告归期公职冻结不代理（参数沿用，权当"摄政静默期"——动员节奏等原参数继续生效），不触发代理。
- **失期（无告假长离）**：无告归且连续离线 → 第 3 旬起进入代理（X2）；第 6 旬 → 暂摄/重选（X3）。
- 告归申请不可代行（身份基座）；AI 君主对告归"准假"人格化回应（韩忧患型挽留、楚豪爽型放行——低成本人格戏）。

### 3.2 X2 梯次代理

- **摄政**：次席自动代摄（每国 1 正 1 副设计的第一性用例），权限七折（§4.3 折扣表），动用**次席自己的临时威望授信 50**（不从原主威望池扣——防代理烧原主资本），代理政绩计入次席考评但不升正（A2）。
- **席位持有者**（相邦/上将军/司徒…）：无副职设计 → 失期第 3 旬 **AI 君主暂收席位**（诏令公示）→ 空缺走补选（S5 选举）；**原主回归后若席位仍空缺，享复任优先权**（免推举直接复任，AI 终审人格化确认）。
- 代理关系全国公示（A5）。

### 3.3 X3 印绶暂摄与让贤

- 失期第 6 旬：摄政印绶暂摄（罢免-lite："印绶暂收，待卿归来"，威望**半数保留**转回归礼包——比 S8 RECALLED 宽，因为失期不是罪）+ 次席转正？**不转正**（A2）——印绶暂摄期由 AI 君主"亲政"（国格自动运转：任务潮照发、廷议关闭）直至季末重选；席位重选同规则。
- **回归通道**：暂摄玩家回归 → 跨季遗产/履历/恩怨全在 → 以大夫档资格重新参与下季竞选；若次席当季表现优异，那是次席自己的政绩——原主与新摄政的竞争下季见（政治叙事自然生长）。

### 3.4 X4 代理制衡

- 代理摄政的全部动作带 `deputy=true` 透明标记（全国可查，与守舍报告同一审计管线）；
- **代理不可弹劾原主**（利益冲突，A2）；
- 代理受同等威望约束与白名单校验（无特权）；
- 原主**随时可上线收回**（玩家主权：回归即接管，交割见 X5）。

### 3.5 X5 回归交割

原主上线 → 代理即时结束（在线优先，主权原则③的公职版）→ 生成**《交割簿》**：代理期做了什么/威望收支/待裁决事项（未结算可撤销，衔接 override 流水）——叙事化包装复用守舍报告模式（"代摄旬余，谨守其政：任务潮依序，粮秣未动，唯廷议一桩待主亲裁"）。

### 3.6 X6 客卿边界澄清

- **代理 = 人对人**（次席代理摄政、AI 暂收席位）；**守舍之约 = AI 对私产**。守舍之约**不覆盖公职职责**：离线摄政的客卿可以照看其私产（任务/私兵/俸禄），但**不能行使摄政权限或席位权限**——公器不托 AI（S7 白名单"仅限手动"清单扩充：公职动作在原主离线期对客卿同样封闭，代理人对代理行为负责）。
- 一句话铁律化：**客卿管玩家的私产，代理管国家的公器，两者永不相交。**

## 4. 数据规格

### 4.1 离席状态机

```
ONLINE ──告归申请──→ LEAVE(告归,≤2旬) ──期满回归──→ ONLINE（交割）
   │                      │期满未归
   │无告假连续离线         ↓
   └──────→ ABSENT(失期) ──第3旬──→ DEPUTIZED(代理:次席代摄/席位暂收)
                │                      │第6旬
                └────第6旬────────────→→ SUSPENDED(印绶暂摄/席位重选)
                                          │原主回归──→ RETURNING(交割+复任优先权)
```

| 字段 | 类型 | 示例值 | 说明 |
|---|---|---|---|
| `absence_id` / `player_id` | string | | |
| `state` | enum | `"DEPUTIZED"` | ONLINE/LEAVE/ABSENT/DEPUTIZED/SUSPENDED/RETURNING |
| `leave_xuns` / `absent_xuns` | int | | 告归/失期计数 |
| `deputy_player` | string | | 代理者（摄政=次席；席位=空缺补选前无） |
| `deputy_prestige_pool` | float | `50` | 代理临时威望授信 |
| `priority_reentry` | bool | `true` | 复任优先权登记 |

### 4.2 告归申请 schema

`{leave_id, player_id, role(摄政/席位), xuns(1-2), reason_text(叙事化，不强制真实), signed_at, approved_by_lord(人格化回应), audit}`——不可代行（身份基座）。

### 4.3 代理摄政权限折扣表（七折定稿 ▲）

| 权限 | 原主（在位） | 次席（代摄） | 折扣逻辑 |
|---|---|---|---|
| 任务潮优先级 | 排序 + 主推方向 | **仅排序，主推冻结**（沿用上旬主推） | 代理可维持不可定调 |
| 战时动员节奏 | 可调参数 | **冻结**（沿用原参数） | 战时参数变动风险大，代理不碰 |
| 俸禄/封赏比例 | 30-70% 滑杆 | **冻结** | 封赏是收买人心的权力，代理不可用 |
| 廷议议题发起 | 每旬 1 次 | 每旬 1 次（保留），但**强推威望消耗 ×1.5** | 代理的对抗性动作成本上浮——合法性弱于原主 |
| 威望池 | 本人威望 | **临时授信 50，独立池** | 防代理烧原主资本 |
| 轨迹 | — | 全动作 `deputy=true` 透明标记 | 代理公开化 |

### 4.4 失期阶梯建议值（▲）

| 阶段 | 触发 | 效果 |
|---|---|---|
| 告归 | 主动申请，连续 ≤2 旬、每季累计 ≤4 旬 | 公职冻结（参数沿用），不代理不停俸 |
| 失期宽限 | 无告假离线第 1-2 旬 | 停俸，公职悬置待归 |
| 代理启动 | 第 3 旬 | 摄政→次席代摄（七折）；席位→AI 暂收+补选 |
| 印绶暂摄 | 第 6 旬 | 摄政罢免-lite（威望半数保留）、席位重选；AI 亲政至季末重选 |
| 回归 | 任意时点上线 | 即时结束代理→交割簿→复任优先权（暂摄前回归原职可复任；暂摄后走下季竞选） |

## 5. 玩家交互流程（四视角）

| 视角 | 体验 |
|---|---|
| **离线高位者** | 离线前：告归申请（人格化准假）或直接离线；回归：《交割簿》+复任通道——**公职可失，家业与名望永在** |
| **代理者（次席）** | 代摄通知+临时威望授信 → 七折执政 → 交割簿回禀原主 → 政绩入自己考评（不升正）——"代摄是露脸不是夺位" |
| **国内其他玩家** | 全国公示的离席/代摄状态 → 透明日志查代理轨迹 → 补选席位时知道"上一位为何空缺" |
| **敌国玩家** | **离席状态公开可查（定稿：透明）**——敌方摄政告归 = 潜在战机（外交施压/边境摩擦的好时机），本国代摄期 = 威慑下降。理由：①透明日志承诺的自然延伸，隐瞒技术上不可实现（行为可观测）；②"邻国伺隙"是先秦战略博弈的真实纹理，公开把离席转化为**两国玩法**而非单国bug；③对离线者的保护已由"公职参数冻结+AI 兜底"承担，无需信息隐瞒 |

## 6. 边界与依赖

| 系统 | 关系 |
|---|---|
| S7 客卿 | **守舍之约不覆盖公职**（X6）：离线高位者的客卿照旧管私产（任务/俸禄），但摄政权限/席位权限对其封闭——白名单"仅限手动"清单按离席状态动态扩充 |
| S8 摄政 | 次席代摄=每国 1 正 1 副的第一性用例；印绶暂摄是 S8 RECALLED 的失期变体（宽于弹劾）；Q4 结案 |
| S5 官职声望 | 席位补选/复任优先权/代理政绩入考评/威望授信流水 |
| S1 快照 | `seat_influence` 代理期语义：**代理者的席位权重生效、原主权重失效**（快照时点在任者=代理者，语义自洽，无需新机制） |
| S3 会战 | 战时告归受限：会战窗口内摄政/兵符持有者不可告归（开战责任）；失期战时代理照常 |
| 透明日志 B7 | 代理全标记、离席状态公示 |

## 7. MVP 裁剪

| 模块 | MVP 实现 | 砍掉/简化 | 恢复时机 |
|---|---|---|---|
| X1 告归制 | **砍** | 全部 | V1 |
| X2 梯次代理 | **最简版**：MVP 齐国摄政无次席（S8 §7.2）→ 失期第 2 旬 **AI 收回印绶**（复用 S8 R7 RECALLED 通道+AI 任命补位，均为既有 MVP 机制） | 次席代摄（随次席 V1 上线）、席位代理（MVP 仅 2 席/国，空缺 AI 任命已覆盖） | V1 |
| X3 暂摄与让贤 | 简版：失期收回走 RECALLED（威望半数保留），回归走下季竞选 | 复任优先权 | V1 |
| X4/X5/X6 | 随代理机制 V1 上线 | — | V1 |

MVP 砍留理由：MVP 只有 1 个摄政位且无次席，"次席代摄"没有承载者；既有 RECALLED+AI 任命已构成最小闭环（政治不永久停摆+离线者不丢资产），告归/代理/交割的完整礼制 V1 一次做对。

## 8. 验证指标

### 8.1 核心指标

| 指标 | 定义 | 目标值 | 采集 |
|---|---|---|---|
| **摄政位空转率** | 摄政离线且未代理（或未收回）的旬占比 | ≤ 5%（V1：≤2%） | 状态机日志 |
| **代理接管时长** | 失期到代理启动的平均旬数 | = 3 旬（阶梯标定兑现） | X2 |
| **失期收回率** | 进入暂摄的离席比例 | 10%-25%（过高=告归制没用，过低=阶梯太松） | X3 |
| **回归玩家留存** | 暂摄/被代理玩家回归后 4 旬留存 | ≥ 全服均值 85% | 分群 |
| **复任优先权使用率** | 回归后走复任通道的比例 | ≥ 40% | S5 |
| **趁虚玩法发生率** | 敌国在对方代摄期发起摩擦/施压的比例 | ≥ 15%（G5：公开情报真的被用起来） | S3/S6 联动 |
| **代理滥用率** | 代理期违规动作（越权/烧威望异常） | ≈ 0，异常 100% 处置 | K6 同源 |

### 8.2 护栏指标

| 指标 | 阈值 | 说明 |
|---|---|---|
| 代理转正数 | 0（规则性禁止） | A2 |
| 影子摄政（离线挂名吃俸）案例 | 0（失期第 3 旬必停俸） | A3 |
| 代理动作透明标记率 | 100% | X4 |
| 客卿公职越权尝试 | 网关拒绝率 100% | X6/S7 联动 |
