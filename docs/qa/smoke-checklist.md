# 试玩版烟雾测试清单（人工执行）

> 产出：严守真（QA-001 静态审查）。对应修复批次：QA 修复一（S1-S5 严重项 + M 级）已于同批应用。
> 执行顺序即优先级；每步记录 通过/失败 + 截图。失败项回传后补回归用例。

## 主干（约 10 分钟）

1. 【观政】开页 → 点"先观政"。预期：进入秦视角只读界面，五维/天下闻可见；点任务/下一旬/上书均弹"观政模式"提示。
2. 【登录-手机】非法手机号 → 提示格式错误；合法号码 → 发送成功且按钮进入 60s 冷却；错误验证码 → 停留登录页；正确 → 进入择国页。
3. 【择国】三国卡片显示完整描述（君主画像+人格文案）；未选国时"入朝为士"禁用。
4. 【办差】办一件任务 → 国力条变化、履历+1、声望+4（成）/+2（蹉跎）；同旬再办 → "本旬差事已办满"。
5. 【上书】点上书 → 日志+1；再点取消 → 日志不变；快速连点 → 无重复行。
6. 【方略】"推行方略" → 成功后禁用、对应维+2；刷新后仍禁用（服务端计数）。
7. 【进旬】"进入下一旬" → 旬号+1、新诏书；断网点进旬 → 错误提示且界面不残。
8. 【双开并发】两标签页同国：同旬同时进旬 → 旬号不得跳 2；各办一件差 → 国力增量各自生效（原子自增验证）。
9. 【会战】秦推进到第 4 旬 → 会战开场；做 ⚔ 任务 → 节点进度推进；三城陷完 → "会战终局"。
10. 【赛季】第 12 旬进旬 → "太史令曰"史书出现、旬号回 1、五维回 40；**关键：新季第 1 旬诏书必须是全新内容（不复播旧季）**。
11. 【刷新恢复】中途刷新 → 回到当前旬，任务/声望一致，无可重复任务。
12. 【弃官重修】confirm 弹窗 → 重载回登录页；重新登录 → 进度仍在。
13. 【认领】先游客玩几旬 → 登录 → "已认领旧游客进度"，国家/声望延续。
14. 【客卿】错误密钥 → "客卿失手：接口返回 xxx" 不卡死；有效接口 → 解读/代拟/代办正常，代办计入差事次数且日志带【客卿代笔】；确认云库中无密钥。
15. 【加载态巡检】以上每步观察遮罩：任何报错后遮罩必须消失。

## 深项（可选）

16. 【会战时钟】楚国玩家把楚推到第 4 旬而秦停在第 2 旬 → 不应触发会战结算错乱（时钟以秦行为准）。
