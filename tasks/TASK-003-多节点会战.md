# TASK-003 多节点会战

## 目标
把试玩版的单战线会战升级为 S3 设计的"节点推进制"：3 个城邑节点依次攻防，会战更有层次。

## 依据文档
- `docs/design/systems/GDD-S3-会战国战.md`（节点定义表、会战阶段状态机、兵符/节杖）
- 试玩版现状：`game/index.html` 中 `warState`/`settleWar`/战时任务 `war_side` 逻辑

## 验收标准
1. 会战改为 3 节点（如秦楚剧本：丹阳 → 鄢 → 郢），必须按序攻破；
2. 每节点独立进度 0-100，攻方任务推进当前节点，守方任务退还进度；
3. 节点陷落给双方不同的国力增减与"天下闻"叙事；
4. 单战线进度条改为 3 节点小地图（可用简单方块，不必图片）；
5. 满 3 旬未打完按当前节点结算。

## 规模
中。注意数据结构变化要向后兼容已有存档（旧 war_progress 字段可迁移或作废）。
