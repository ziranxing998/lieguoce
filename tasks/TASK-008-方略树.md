# TASK-008 方略树

## 目标
实现"文明系玩法内核"的核心转译：国家级长期研究线。文臣推动"变法/水利/军制/历法/纵横术"等方略，一旬推进一格，全国共享收益——文臣"制定策略"的长期玩法载体。

## 依据文档
- `docs/design/GDD-0-游戏概念文档.md` §五"文明系玩法内核转译"小节（防冲突核心条款：方略树不生成任务、不占任务潮配额）
- `docs/design/systems/GDD-S2-国力五维.md`（方略树收益归因入策功链）

## 验收标准
1. 每国 4 条方略线 × 6-8 格（首版可只做 2 线试点）；
2. 玩家"推动方略"是一种任务类型，完成后该国当前方略推进一格；
3. 每格效果写入国家加成（如"水利 II：民生自然衰减减半"）；
4. AI 君主旬决策 prompt 中包含方略树状态（token 预算 ≤200）；
5. 试玩版 UI：国力面板下方加一行"当前方略：某某·第X格"，点击可看全树。

## 规模
中。数值（每格效果）需附推导说明。
